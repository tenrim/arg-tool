# 迷雾工具箱 · 1Panel 部署

当前标准部署使用 Node.js 24 或更新版本，运行仓库根目录的 `npm start`，统一管理网站、在线资料查询及已配置的邮件反馈。更新通常是同步代码后重启原运行环境；具体配置保留、验收及回退限制见 [当前部署与恢复说明](../docs/DEPLOYMENT.md)。

以下章节是**仅交付静态目录时的替代方案**，不能启动在线查询或邮件服务。普通工具输入和所选文件仍在访客浏览器内计算；主动联网查询、问题反馈和原站访问另有各自的数据去向说明。

## 1. 新建网站

1. 在 1Panel 的应用商店安装并启动 OpenResty。
2. 打开「网站 → 创建网站」，选择「静态网站」（不同版本菜单名称可能略有不同）。填写自己的域名，创建网站。域名的 A/AAAA 记录应指向服务器；暂时没有域名时可用面板支持的 IP/端口方式检查静态文件，但正式使用需要 HTTPS。
3. 从该网站的「网站目录」进入实际根目录。以面板显示路径为准，不要照抄其他服务器的 `/opt/1panel/...` 路径。
4. 上传本包内的 **site.zip**，在网站根目录解压。解压后根目录应直接出现 `index.html`、`app.js`、`ui/`、`vendor/`，不能套一层 `dist/` 或 `site/`。删除上传用 ZIP；不要把整个外层交付包、项目源码或测试目录放进网站根目录。
5. 将默认首页设为 `index.html`。静态文件通常采用目录 755、文件 644，并保留面板网站用户可读权限，不要设成 777。

## 2. 配置与 HTTPS

- 在网站配置中参考 `1panel-locations.conf`，把片段合并到该网站现有的 `server {}` 内。它不是完整配置文件，不能覆盖面板生成的监听、域名、网站 root、SSL 和证书验证配置。
- 如已存在 `location /` 或 JavaScript/WASM 静态规则，请修改现有规则；避免重复 location。更新时完整替换发布包，不能只上传 `app.js`；当前页面还需要 `ui/` 中的组件模块与样式。取消 JS/CSS/HTML 的长期 `expires` 或 `immutable` 缓存，采用重新验证缓存。
- 本站使用 `#crypto` 等 hash 路由，无需 SPA 伪静态回退。不要配置 `try_files ... /index.html`，否则缺失的 Worker/WASM 会收到 HTML 而运行失败。
- OpenResty 标准 `mime.types` 应已包含 CSS、JSON、SVG、字体等。片段额外指定 JavaScript 模块和 WASM 类型。不要启用拒绝 Worker、blob: 或 WASM 执行的额外 CSP，除非经过完整浏览器回归。本站不需要开启跨域访问或添加 `Access-Control-Allow-Origin: *`。
- 资料查询始终请求 `.json`，避免将 `.gz` 压缩包地址交给 IDM 等下载管理器。片段的 `gzip_static on` 仅在浏览器接受 gzip 时提供同名压缩副本，响应仍须为 `application/json`，并带 `Content-Encoding: gzip` 与 `Vary: Accept-Encoding`；不要设置 `Content-Disposition: attachment`。缺少 gzip_static 模块时移除该指令即可，完整 JSON 不依赖压缩或后台服务。
- 在 1Panel 中申请或导入域名证书，开启 HTTPS，并按需要启用 HTTP 跳转 HTTPS。浏览器的部分加密与 Worker 能力要求安全上下文；IP 上的普通 HTTP 不能作为正式验收环境。
- 保存时执行面板配置校验，通过后重载 OpenResty。该参考片段还需由目标服务器的实际配置校验，不能跳过。

## 3. 上线验收

分别用电脑和手机打开 `https://你的域名/`：

1. 默认首页只显示已收藏、最近使用和工具导航。电脑端保留可收起侧栏，手机同节点抽屉可访问编解码与加解密／资料查询／图片音视频与文件处理／其他工具四类。每类总览显示全部能力组、代表功能及真实数量；“全部 N 项”就地展开完整列表，全部功能目录一层可搜。顶部搜索默认跨四类，原工具深链接、收藏与设置仍可用。数字电路、几何作图、图论路径和图片 OCR 无入口，任务切换不打开额外页面。
2. 从资料查询进入天文、元素与化学、传统历法，从其他工具进入蛋白质与核酸处理；农历反查、DNA 转译、SMILES 结构各执行一次。Base64 的两个方向与加解密实际可运行；修改输入或切任务时旧结果立即失效。代码运行中 Python 和 JavaScript 各运行一次，视频处理可载入本地短视频。首次启动较大的引擎会下载本站固定运行文件，应等待完成。
3. 碎片拼接上传两张图片：手机单指拖动、双指缩放，锁定后不可误拖；撤销/重做有效；导出 PNG 尺寸与画布设置一致。电脑可滚轮缩放、空格拖动画布，参数在侧边。
4. 使用说明原地展开，正文无重复静态说明；使用第三方代码、数据或素材的任务最后显示实际来源链接和精确许可，纯本站实现不显示来源栏。关于页保留集中许可，设置修改即时生效且不清除工具输入。
5. 打开开发者工具 Network：页面资源无 404；`ui/index.js`、`ui/pages.js` 与 `ui/components.css` 均可加载，`.js` 返回 JavaScript MIME，`.wasm` 返回 `application/wasm`。随便请求一个不存在的 `/missing.js` 应返回 404。
6. 抽屉打开时将窗口从手机宽度放大到桌面，侧栏恢复桌面状态；如果桌面原本已收起，应继续保持收起。Esc 关闭手机抽屉后焦点回到菜单按钮，已填内容保留。
7. 更新后重新打开或刷新网页，确认没有运行包版本混用。若接入 CDN，按同样策略重新验证或清除站点缓存。

当前本地回归结果见仓库的 VERIFICATION.md。浏览器模拟视口不能代替实体安卓/iOS 设备和服务器验收；域名解析、证书、面板配置及真实网络需在目标环境确认。源码托管在 Gitee 不代表网站已部署，旧 Sites 配置也不代表 1Panel 状态。

## 4. 更新与回滚

更新前使用 1Panel 网站备份功能保存旧网站文件和配置。推荐先解压新版本到独立目录，确认 `index.html` 与 `vendor/` 齐全后，将网站根目录切换到新目录；不能切换目录时，可在维护时段替换整个静态文件集。不要覆盖保留多版 vendor，否则删除的工具资源可能继续公开。保留面板的 ACME 验证目录和证书配置。

失败时将网站目录切回旧目录，或从面板备份恢复旧版本。不要只回滚 HTML 或单个 JS，页面与运行包应来自同一个版本。数据并不保存在业务服务器上，但浏览器里保存的配方/草稿仍属于用户本机数据。

## 5. 包内容与校验

- `site.zip`：只包含可发布网站文件，根层直接是 index.html。
- `site-files.sha256`：逐文件 SHA-256 校验清单；解压后可在网站目录执行 `sha256sum -c /清单所在路径/site-files.sha256`。
- `release.json`：打包时间、源码基线、文件数量与静态内容摘要。源码基线不替代逐文件摘要。
- `SHA256SUMS`：交付包内主要文件校验值。
- `1panel-locations.conf`、本说明：部署参考，不需要放到公开网站目录。

开发者重新打包：Node.js 24、Python 3，先 `npm run verify`，然后 `npm run release -- --out /tmp/arg-release`。发布脚本检查 dist 与 public 完全一致、无遗留删除工具，再创建 ZIP 并验证归档 CRC。


资料查询验收：在对应能力组中检索中国与国旗、PEK 机场、CNSGH 上海港、U+1F600、六十四卦、塔罗“力量”、#ff0000、距今 150 百万年、1,1,2,3,5,8。晶体选择金刚石进入现有三维观察，应显示一个晶胞 8 个原子；两倍晶胞为 64 个。确认子目录安装时 Worker 与数据文件无 404，停止后不显示迟到结果。数列精选库和 CIF 支持范围见 README，不依赖远程数据库。


可视浏览验收：点击地图中的中国或国旗目录，验证资料；同一世界地图和当前国家上下文可切换货币、机场、运输地点，查询详情不得混入旧任务结果；检查交通资料当前页圆点。八卦切换先天/后天，组合上坎下震应显示屯；字符表点 U+2200、塔罗点力量、色板点红、年代逐级进入侏罗纪、数列点斐波那契。金刚石目录预览应显示 8 个展开原子。手机放大地图后拖动/双指缩放不应误选国家，点选资料后应能看到详情并返回图形；确认菜单与能力组图标显示，地图资源本地加载；恒星／深空目录选中实际对象后联动方位查询，保留用户时间与地点。普通和减少动态效果、键盘导航、手机横屏均可操作。
