共享 UI 的 `mountFloatingAction` 持有当前文档唯一的悬浮操作栈，原按钮节点直接移入，主要入口排在底部。输入键盘使用同一接口，移除工具 CSS 中的独立固定定位；按原焦点逻辑显隐并保留插入选区、弹窗及销毁逻辑。公共组件 CSS 负责安全区、48px 点击高度、间距、层级、配色和打印隐藏。
