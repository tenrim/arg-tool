# 2026-10-26 共用 UI 修复与逐页截图

用户要求检查附图以外的同类问题，直接修复并保留前后对照。本轮修改位于本地工作区，尚未部署；未提交或推送。

## 发现与修复

| 问题 | 所有者与原因 | 修复及证据 |
| --- | --- | --- |
| 黑色琴键悬停／聚焦变白 | 移动高亮适配把原按钮背景清空；重叠琴键因此透出下方白键 | Button 支持 `appearance:'custom'`，图形表面不交给菜单高亮；琴键外观移入共享组件样式，按压动画、原键盘事件和播放状态保留。悬停背景由透明变为不透明，实际 C#4 按压仍显示强调色，松开复位。 |
| 参数输入与右侧按钮高低不齐 | 部分旧行没有通过 Toolbar 工厂；Field 自带外边距且操作栏垂直居中 | 模板的 `r1-controls`、`spectrogram-controls` 使用共享 Toolbar；直接 Field 的外边距归零，整行按底边对齐。BPM／播放、MIDI 音轨／导出原差 12px，修复后差为 0；音频导出和 WPM／WAV 同样对齐。替换密码、五线谱等直接消费者一并检查。 |
| 媒体来源输入卡片有大量空白 | 转换分栏默认等高，来源选择卡片被结果及其按钮撑高 | ConversionLayout／Workbench 返回真实 `panes`，输入模式所有者选择 SplitView 的现有 `start`／`stretch`。媒体来源和摩斯解码按内容高度，文字输入保留成对编辑区等高。元数据输入由约 308px 降至 169px；摩斯音频输入由约 307px 降至 193px；来源／方向切换保留草稿。 |

没有逐页加高度补丁、固定等待或隐藏错误。未更换、升级或复制第三方依赖，现有 Animate UI 普通按钮高亮和按压继续使用。
