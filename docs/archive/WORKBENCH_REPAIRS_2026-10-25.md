# 工作台十二项修补

本轮承接用户确认的问题表，保留进入本轮前的未提交改动。版本仍为 V1.4，本轮不提交、推送或部署。

| 原问题 | 实施 |
| --- | --- |
| 收藏混淆 | 按 registry 工作区身份保存，保留实际成员／方向，首页、侧栏和收藏目录共用目标解析 |
| 上次工具恢复错误 | 保存规范化的完整公开任务路由，新文档恢复真实工具 |
| 资料详情不在视口 | 共用 reveal 同步处理目标可见性及真实焦点，返回资料目录亦使用相同机制 |
| 入口脚本失败无反馈 | 独立 guard 捕获模块入口下载错误，重试保留深链接，静态重试入口始终可见 |
| 科普重复文献 | 专题投影按文献身份合并，保留机构与章节，重映射所有成员和小节 sourceIds |
| 科普返回焦点不可见 | 同时恢复条目焦点及内外滚动容器中的可见位置 |
| 设置选项重复 | 启动页面选项由同一功能投影生成，专题只列一项；旧版偏好及备份继续可导入 |
| 手机换算结果太远 | 数值与结果同排，公共 FormGrid 支持起点对齐，缩短软键盘出现时的查看距离 |
| 单位名称与内部记号混杂 | 补齐本包 452 项的中文名称，常用符号易读化，原始计算记号移入详情 |
| 鸟类默认列表难用 | 默认只浏览种，中文名优先；按目索引折叠，全部分类、原字段及完整工作簿保留 |
| 长文缺目录 | 四节及以上文章提供可折叠的小节目录，点击后定位并聚焦真实标题，正文保持全宽 |
| 等号键操作不一致 | 普通模式键盘 = 执行计算；科学模式保留等式输入，Enter 及页面等号仍执行 |

## 参考编码

先经 XERJ 查本项目所有者，再查最相关参考库，回到固定源码核对；没有复制上游代码，也没有调整任何第三方运行包或引入新依赖。

- IT-Tools，`d505845f918e946ec300af7b36efc107e2f66e9e`：`src/tools/tools.store.ts:39–66` 用唯一工具路径持久保存收藏，由工具目录解析显示对象。本项目多成员共享面板，因此保存目标须进一步使用 registry 的公开工作区和规范路由，不能直接沿用面板 ID。
- Omni Tools，`60bc64f5a6974f3c802c5ec06cb3cf7f824485e1`：`src/components/ToolHeader.tsx:49–51` 以真实目标节点执行滚动。本项目同时恢复焦点、处理内层目录滚动与固定页头，不采用其另一个带固定延时的可见性检查。
- libqalculate，`132d7b2f150de1ace81c02a93701a012e10fb97c`：`libqalculate/ExpressionItem.h:135–147` 区分 preferredInputName 与 preferredDisplayName。本站实际绑定只提供目录名称与原记号，因此在显示层转换记号；不假设 WASM 新增了该 C++ API，不更新内核，不复制换算倍率。
- 科普引用合并属于本站内容模型，未在上述参考项目中找到等价契约，沿用本项目 sourceIds 校验实现。
