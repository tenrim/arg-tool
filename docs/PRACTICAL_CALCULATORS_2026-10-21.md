# 实用计算功能（2026-10-21）

本轮按用户选择落实通用、客观、输入明确且可直接得到结果的计算，覆盖解谜、资料核对和日常核算。不是把外站计算目录整体搬入，也未使用 IO Tools 的代码、页面或素材。

| 入口 | 本轮行为 |
| --- | --- |
| 日期加减 | 公历年、月、周、天加减，明确先合并年月、月末截取、再加周与天 |
| 日期差 | 有向差、含／不含结束日、总天数、周数、周一至周五计数和日历年月日间隔 |

| ISO 周与年内日序 | 日期与 ISO 周双向转换、周所属年、星期、本周起止和年内第几天 |
| 跨时区会议规划 | 1–12 个地点、完整 598 个时区、各地起止日期／时间／偏移、可用时段及周末条件；未来 7 天每半小时寻找共同空档，最多 12 档 |

几何覆盖长方形、正方形、三角形三边、三角形底与高、直角三角形、平行四边形、等腰梯形、一般梯形面积、圆、圆环、扇形、正多边形、长方体、正方体、圆柱、圆锥、球、半球和正四棱锥。半球明确区分曲面与含底表面积；所有长度使用同一个所选单位，面积／体积显示其平方／立方。

日期类、会议和地理入口在“其他工具 → 坐标与时间换算”；几何与 BMI 在“其他工具 → 数学计算”；摩尔质量沿用“资料查询 → 元素／物质”原任务，并可通过搜索找到。

## 计算口径与边界

- 公历日期支持 0001–9999 年，不用本机时区做天数差。周一至周五不等于已扣除节假日的法定工作日。日期计算与生日约定不作为法律年龄规则。
- 倒计时以电脑时钟为准，一天指实际 24 小时。修改输入或离开页面立即清除结果租约并停止刷新；返回后须主动开始。目标已过后显示经过时长。
- 会议使用既有完整固定 TZif。未来政策可能修改规则。会议时长是实际分钟；本地时间不存在时失败，重复时须明确选择先后。地点可用时段是同一天内的范围，不能用起止相同表示全天，也不代入假定节假日。
- 地理距离使用平均半径 6371.0088 km 的球面大圆，不是椭球精密测量或道路里程。方位按真北顺时针；重合、对跖和极点不输出不唯一方向。
- BMI 只计算数值，不做诊断或儿童青少年分级。英尺是十进制英尺，5 英尺 6 英寸应输入 5.5 英尺或 66 英寸。
- 摩尔质量使用随包完整 118 元素表中的原子量近似，不是精确同位素质量。分子式区分大小写，不支持电荷、同位素标注或小数下标。点号和 * 明确作为结晶水分隔符。

## 所有权和来源

`practical/catalog.js` 仅声明静态能力；navigation／registry 仍统一拥有侧栏、搜索和深链接。`practical/dates.js`、`geometry.js` 为纯计算／表达式模型；`index.js` 拥有表单、各图形草稿、同步失效、复制下载及笔记租约；`time-client.js` 是既有 TZif Worker 的独立可取消客户端。

`timezones/planner.js` 只处理当地时间消歧和多地时间规划，原 `timezones/core.js` 继续拥有唯一 TZif、POSIX 及历史偏移模型。`worker.js` 在同源完整目录中校验时区标识，不接受任意 URL。既有历史时区查询协议保留。

`round2/coordinates-engine.js` 继续独占坐标解析与距离／方位算法。原距离表单与监听移除，避免两份距离计算界面；原坐标／时间戳输入、反向解码和笔记入口保留。

几何与 BMI 使用既有 Qalculate；摩尔质量使用既有完整元素表；倒计时和会议使用既有 IANA、PSF、CLDR、OpenCC。原 vendor 字节和许可没有改动。消费者及用途登记到 `project-source-contracts.js`、关于页许可目录和真实任务页末；原创日期和球面表单显式声明空依赖，不制造空来源栏。固定复用记录见 `upstream/practical-20261021/SOURCES.json`，新增用途 notice 在 `public/licenses/PRACTICAL-CALCULATORS-NOTICE.txt`。
