## 与原审计范围的关系

- 原网站重叠功能继续使用已存在的实际引擎，例如普通二维码识别、九键、六点盲文和旗语索引；没有为同功能额外复制一套页面。
- K30 原表收集了 Branah 的大量语言子页。这里交付的是用户选定 O26／O27 的完整开源布局包，不声称覆盖 Branah 的每一种语言或它的词典输入法。46 套布局之外的语言没有被包装成“已支持”。
- K29 原表还包含商业托管平台、停用归档和 Trillcode 等不属于所选开源引擎的项目；本轮没有声称取得这些服务代码。111 个制式也不意味着 ZXing 可以识别它们全部；生成与识别保持真实引擎各自支持范围。
- Monkey 的旧评估将其误描述成“候选约束”工具；它实际是旗语、盲文、摩尔斯和氨基酸的交互辅助页面。本站已有相应真实转换／查询，本轮没有复制无明确许可的网页脚本。
- NGA 海事规则采用国际信号规则的三个代用旗，不把其他海军体系的第四代用旗混入同一标准。全书原文保留，不用少量常见组合代替完整码本。
- GS8 原作者表中数字 0 与 u 同码、phi 重复点号及两项 underline 均保留并说明；只归一点号集合，不擅自给原表纠错。反向输出歧义候选，不伪造唯一译文。

## 数据与生成

原始归档：`upstream/completion-20261017/`；逐文件摘要：`SOURCE_FILES.json`；归档摘要：`SOURCES.json`。运行包：`public/vendor/completion/`，896 个文件及完整摘要清单。

普通构建离线。维护导入器只在主动更新时联网：`scripts/import-gs8.py`、`scripts/import-marine-codebook.py`。离线生成器 `scripts/build-completion-vendor.mjs` 先验证原始文件，再生成适配包。原项目源码、许可证和独立依赖 notice 随包保留。

所有计算在本机运行，不因已有后端而上传玩家文件。输入超出设备／运算限额会明确失败，不能把截断结果当作成功。

## 联动与界面

使用现有任务壳、专题选择、CRT 风格和 ConversionWorkbench。计算结果可加入笔记／图稿；字节和图形附带完整附件。折纸记录包含完整当前 FOLD 网格和原文件元数据。改输入／参数、离开任务、停止时清除旧结果租约；未明确采用的二维码修复不改变原矩阵。

来源页脚按当前真实算法显示；自有规则不伪装成开源依赖。所有新增任务有科普与使用说明。本轮验证结果见下节。
