# 本地资料中文适配

本轮针对 [语言排查清单](REFERENCE_LANGUAGE_AUDIT_2026-10-17.md) 处理本地资料。在线查询的正文、字段和名称适配留待后续；没有修改在线服务，也不在用户查询时调用翻译服务。

## 处理原则

- 原始数据库的记录、标识、字段、完整收录范围和原文继续保留。中文作为附加名称、别名、说明和检索词，不替换标准名称。
- 仅采用已经存在、许可允许的中文资料，或对权威／可靠来源做可复核的批量对应。不逐条人工写译名，也不让机器凭标题猜译文。
- 同一实体必须通过标准标识、严格身份及必要的坐标／生卒信息核对。重复、冲突和无法确认的对应不导入；中文名称覆盖率与原始数据库记录数分别计算。
- 没有取得可靠批量来源的部分，在实际页面说明原文范围与检索方法；不能把网络获取失败说成世界上不存在中文资料。
- 中文补充、繁简归一化和检索全部在本地运行。维护导入器需显式执行，普通构建和用户查询不访问上游。

## 固定来源与维护

- [Unicode CLDR](https://github.com/unicode-org/cldr-json/tree/48.2.0)：Unicode License v3。原始选定语言文件、版本、摘要位于 [upstream/cldr](../upstream/cldr/PINS.json)，运行说明和许可见 [NOTICE](../public/vendor/cldr/NOTICE.txt)。离线生成：`node scripts/import-cldr.mjs`；显式重新下载加 `--download`，仍须满足既定摘要。
- [MDN 中文参考](https://github.com/mdn/translated-content/tree/e7abcf317df79ab57e6053f48c8b1fec01920836)：正文和派生说明 CC-BY-SA-2.5，署名 MDN contributors。选定完整页面及精确版本见 [SOURCE.json](../upstream/reference-mdn-zh/SOURCE.json)。离线生成：`node scripts/build-reference-mdn-zh.mjs`；维护下载：`node scripts/import-reference-mdn-zh.mjs`。不抽取示例代码和媒体。
- [OpenCC-JS](https://github.com/nk2028/opencc-js)：复用既有固定 1.4.2 运行包，代码 MIT、字典 Apache-2.0；仅做本地检索归一化。
- 鸟类与古典音乐的原件、引用、许可及维护步骤见 [鸟类与音乐补充说明](ATLAS_CHINESE_DATA.md)，固定来源在 [atlas-chinese/pins.json](../upstream/atlas-chinese/pins.json)。
- 地名与天体的固定 Wikidata 查询、全部原始响应及严格对应规则见 [reference-chinese/README.md](../upstream/reference-chinese/README.md)；仅维护命令 `node scripts/import-reference-chinese.mjs --refresh` 联网，默认命令只用固定原件离线重建。

来源必须同时出现在关于页和实际受影响工作区末尾。导入器、完整固定原始文件、许可证、变更说明和运行摘要均随仓库保留；不能仅更新关于页。
