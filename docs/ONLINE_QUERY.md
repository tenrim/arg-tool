# 可选在线资料查询

迷雾工具箱在浏览器本地工具之外，提供可选的服务端资料查询。OEIS 为首项；2026-10-17 按用户选择增加 E09 汉典、E11 搜韵／CNKGraph、E16 SIMBAD、E17 VizieR、E19 COD、E20 PubChem、E23 国家地名信息库和 E34 神奇宝贝百科。每项只包含下表列出的实际模式，不能将接口适配称为整站复制、离线全库或所有功能均已接入。

COD 的适配和回归已完成，但本轮访问官方主机仍连接超时，尚未通过真实上游连通验证；页面保留失败说明和原站入口。其他服务的一次公开样例成功也不保证长期可用。这里记录本地实现范围，不表示已经部署线上。

## 玩家看到的说明

- 每页常驻显示：点击查询后，本次条件会经本站服务器发送到哪一家服务，需要联网；汉典非官方接口、非商业范围、长间隔及数据窗口等限制同时明确说明。
- 首次进入、输入文字、切换模式／页面、选中记录和失败后都不自动查询。翻页、读取完整作品／文献／CIF／结构等后续动作都需玩家明确提交；查询表单先显示将使用的真实参数。
- 使用说明、相关科普、关于页与全站页脚同步解释联网和来源边界。所有服务保留原站手动查询入口，失败不回填演示记录、不偷偷切镜像或自动重试。
- 结果先展示中文标注的关键信息与原文入口，查询元数据和原始 JSON 不在阅读页面展示，完整资料仍随复制、下载和笔记保存。支持当前记录／整页复制或导出及笔记／图稿保存，附原查询、实际参数、来源、时间、署名和许可。显示预览不裁掉保存数据；VizieR 的原始 TSV／XML 和其他原始响应元数据同时保留。
- 停止、输入改变、选择记录、分页、切换模式、任务或离页会立即作废旧保存租约，拒绝迟到结果。停止只能取消本站的等待，不能撤回已经到达外站的查询。

相关来源继续由现有共享来源所有者同时呈现在关于页与各真实任务页末，补充展示说明见 [ONLINE-READING-NOTICE.txt](../public/licenses/ONLINE-READING-NOTICE.txt)。现有固定接口、许可和原始依据的字节摘要保留不变；展示变更登记于两个在线来源 manifest。MediaWiki 版本文字的字段依据为 [官方 Revisions 接口文档](https://www.mediawiki.org/wiki/API:Revisions)，其他字段依据随各服务原归档保留。

## 启动与部署

继续使用 Node.js 24 或更新版本，在仓库根目录运行 `npm start`。网页、可选邮件反馈和在线查询由同一命令管理，共用现有网站端口；查询适配器只使用 Node.js 内置能力，**无需安装新增查询依赖、API Key、单独运行环境或开放额外端口**。邮件配置缺失或 SMTP 尚未就绪，不阻断查询；查询后端不可用也不阻断浏览器本地工具。

1Panel 保持原运行环境、端口及反向代理。在代码已同步到服务器且保留原私密邮件配置的前提下，重启原运行环境即可加载新适配器。此文档不代表已经向仓库推送或向生产服务器部署。

默认允许 `https://www.tool.mistarg.cn`、`https://tool.mistarg.cn` 及实例实际监听端口的 localhost／127.0.0.1 页面。改正式域名时，用进程环境变量 `ONLINE_QUERY_ORIGINS` 指定完整源，多个值用逗号分隔；它替代默认正式域名，不接受通配符、路径、用户信息或结尾斜杠。本机回环源仍按实际端口校验。无需为不同外站增加浏览器跨域白名单。

静态发布包保留全部本地工具；在线查询需要根 Node 服务。纯静态托管时页面明确报告后端不可用，保留原站链接。已有 OpenResty 全站反代到根 Node 服务的部署不需要新增代理规则；单独提供静态文件时，应将 `/api/query/` 交给该服务。不要把静态 ZIP 当作已经包含运行中的查询后端。

## 固定接口与请求边界

浏览器向同源 `POST /api/query/<provider>` 提交 JSON，提供方 ID 为 `oeis`、`zdic`、`cnkgraph`、`simbad`、`vizier`、`cod`、`pubchem` 和 `placenames`、`pokewiki`。每种模式有独立字段白名单，未知字段、控制字符、无效页码和超限条件均拒绝；请求正文最多 8 KiB。

OEIS 保留既有 `{query,start}` 契约：最多 500 字，起点 0–10000 且为 10 的倍数，单独 `A000045` 转为 `id:A000045` 精确查询，同时保留原输入。新增服务接收其真实 `mode` 与对应条件，不接收任意 URL、SQL／ADQL、任意转发标头、账户或用户文件。

上游目标只允许各适配器的固定官方端点：OEIS `search`、汉典公开 `hans/` 词条、CNKGraph 开放 `api/`、SIMBAD TAP／ConeSearch、VizieR ASU／VOTable、COD REST／单条 CIF、PubChem PUG REST／PUG View、国家地名 7 接口以及 52poke Action API。客户端不能选择目标主机；重定向被拒绝，不抓登录页面、不绕过验证码或访问限制。

汉典公开条目 HTML 仅在服务端转换为文字。它不是任意网页代理；脚本、嵌入页面及媒体不执行或加载。其他原始格式同样作为资料保留，不在本站运行其中的程序、HTML、Wiki 模板或图像链接。

SIMBAD 天区的一次明确查询可能先读取官方空间索引，再为当前页匹配完整基本资料；PubChem 可能先读取 CID 列表，再读取当前页完整结构记录；COD 可能先计数，再读符合限额的 JSON。这些是该次查询所需的有界子请求，不是后台爬库，也不自动读取所有匹配条目的详情。

## 限额、取消与隐私

| 服务 | 本站全服务共享的最小外发间隔 | 单次处理总时限／资料限额 |
| --- | --- | --- |
| OEIS | 10 秒 | 15 秒；原接口最多 2 MiB |
| 汉典、搜韵、国家地名 | 10 秒 | 15 秒；累计及最终响应最多 8 MiB |
| SIMBAD、VizieR、COD | 1 秒 | 30 秒；累计及最终响应最多 8 MiB |
| PubChem | 300 毫秒 | 30 秒；累计及最终响应最多 8 MiB，仍可能被上游动态限流 |
| 52poke | 500 秒，遵守原站机器人访问节奏 | 15 秒；累计及最终响应最多 8 MiB |

OEIS 的 10 秒和其他本站保护间隔不是统一的官方 API 配额，也不代表可以批量抓库。单次新增服务请求最多 8 个必要子请求，同一请求的后续外发也计入提供方间隔，并可取消；首次提交太频繁时返回等待提示，不自动排队重试。另有按连接地址、会到期且有容量上限的限流状态，以及所有查询共享的在途请求上限。

本站不向外站转发浏览器 Cookie、访客 IP、文件、笔记、其他工具结果或其他表单字段，只发送本次所选模式所需的条件。经相同反向代理到达的连接可能共享逐地址额度；服务不为区分访客而信任任意 `X-Forwarded-For`。

本站适配器不把查询或结果写入日志、数据库、共享缓存或磁盘，响应使用 `Cache-Control: no-store`；只在处理期间临时保有必要数据和有界限流状态。托管层可能记录访问日志，外站也可按其政策记录请求。主动保存的笔记及附件仍位于玩家当前浏览器，不因在线查询新增云笔记。
