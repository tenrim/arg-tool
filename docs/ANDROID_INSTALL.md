# 迷雾工具箱 Android 安装与更新

本次交付用于直接下载安装 APK，不含应用商店提交或网站部署。

## 首次安装

1. 将“迷雾工具箱-V1.4.apk”传到手机，用“我的文件”打开。
2. 如果系统提示安装来源权限，仅为当前使用的文件管理器按提示允许安装，再继续。
3. 安装后打开“迷雾工具箱”。三星系统如果提示安装拦截，请根据该条提示处理；不需要开启 USB 调试。
4. 本地工具和固定资料随包提供；在线查询与发送反馈需要联网。麦克风只在点击录音时申请，拒绝后仍可使用已有音频文件。

最低允许安装 Android 9，需使用现代 Android System WebView；实际通过本轮验收的是三星 SM-S9260、Android 16、WebView 155。安装包约 272 MiB，安装时还需要额外存储空间。

## 与测试版的区别

正式版应用 ID 为 `cn.mistarg.toolbox`，独立发行证书签名并关闭调试。原“迷雾工具箱（测试）”是另一应用，可以并存；其笔记不会自动出现在正式版。需要迁移时，在测试版导出完整笔记备份，在正式版“笔记本 → 导入 / 导出”导入；收藏与设置也可用原有设置备份迁移。确认备份和导入完成后再自行决定是否卸载旧测试版。

## 更新与数据

今后使用相同应用 ID 和同一发行证书签名的新版 APK，可直接覆盖安装。更新前建议导出完整笔记备份；不要为了更新先卸载应用。卸载、清除应用数据会删除手机上的笔记与设置。

笔记只保存在当前手机的当前应用内，不会自动同步到网页或其他设备。完整备份包含正文、附件和可编辑图稿；大备份可能分批导出，需保存全部分批文件。单次 Android 文件导出上限 128 MiB，超过会提示失败，不会返回截断文件。

## 遇到问题

先在应用中使用“报告问题”，写明操作步骤；附件仅在你主动选择并发送后上传。在线来源不可用时，可使用页面提供的原站入口，本地工具仍可继续使用。SMTP 密码不在 APK 中。
