# 外站资料指南的收录范围（2026-10-17）

`#external-guide` 是网站级资料指南，由 `public/external-guide/catalog.js` 保存原创中文介绍，`page.js` 使用公共组件展示。入口归入侧栏“资料查询”子菜单，全局查找也可进入，不登记为本地计算能力，也不计入工具／科普数量。

按七个方向收录 28 个网站：英文词语与字谜；汉字、日语与古诗文；旗帜、地图与交通；图片溯源、隐写与星空；音乐、旋律与影视台词；专题文化与素材；综合知识与专业参考。同方向列多个网站，每站以完整连贯的中文介绍说明资料范围与网站内容，卡片仅保留站名、详细介绍和原站链接；不再生成“怎么查”“适合的线索”“使用边界”“与本站的区别”等说明栏目。页面支持方向筛选及本机文字检索。

用户明确排除 E27 百度识图、E35 萌娘百科、E38 中文维基百科。E01、E09、E11、E16、E17、E19、E20、E23、E34 已进入在线查询接入范围，本指南不重复列入。E29 介绍 AperiSolve 完整外站扫描，不另列与本站比较。

所有链接均为显式打开外站，不预请求、不嵌入、不代填、不自动上传任何线索。只撰写网站用途介绍，不复制外站正文、图片、数据或代码，不登记为新增开源依赖。原有集成来源与许可保持不变。下文为原审计清单，含已接入及本次排除网站，仅作历史决策依据，不代表全部进入现行指南。

## 后续使用这些链接时的约定

- 每个入口应说明“用来查什么、需要准备什么、返回后记下什么”，而非只显示网站名称；同类服务保留用途差异。
- OEIS 与本轮 8 项适配仅在玩家明确提交查询、翻页或详情动作后发送必要条件；没有进入页面、打字或失败后的自动外发。其他入口仍由玩家去原站使用。在线结果可显式保存到笔记／图稿，保留原条件、完整当前字段、来源、时间与许可；上传图片、音频或文件不属于这些文本查询适配器的功能。
- 查询词本身也可能是未公开线索。未来若做带参数跳转，必须让用户明确看到将发送的内容；不能因当前输入非空就自动请求外站。
- 仅提供外链的服务不冒称已集成引擎或数据，也不加入实现依赖清单。本轮实际读取外部文字／数据的服务按真实任务补齐关于页、页末署名、固定依据和许可／服务条款，不能冒充本地全库或开源代码集成。
- 状态失败的资源在设计正式入口前再次手动核对，不用镜像、社区转载或搜索摘要冒充原站成功。本站不部署抓取代理来绕过验证，也不承诺外站长期可用。
