# 白板、脑图与笔记

线索白板采用 Excalidraw 0.18.1，思维导图采用 Mind Elixir 5.15.1。两者是笔记本的编辑视图，不登记为独立工具；入口为笔记本的“插入脑图／插入线索白板”和当前笔记的图稿索引。路由为 `#notebook/mindmap`、`#notebook/whiteboard`，旧 `#mindmap`／`#whiteboard` 归一到对应视图。

编辑器嵌入笔记本原页面，保留共用标题、笔记列表和当前笔记图稿。图稿视图的“使用说明”由笔记本同一个说明组件显示；“其他工具”、工具目录、能力统计及工具科普不再包含白板／脑图。全局搜索相关名称会找到笔记本入口。

- 白板默认粗糙度 0、实心填充、普通字体；导入图稿也统一到该外观。保留上游真实图形、箭头、图片、文字、排列、分组和撤销功能。
- 深色界面与图稿颜色独立：共享主题将 Excalidraw 的 `--theme-filter` 统一设为 `none`，使色板、取色器、画布和素材预览按实际 HEX 显示；PNG／笔记预览同样使用原始颜色。不能仅取消 canvas 反色而保留色板反色。
- 脑图直接使用 Mind Elixir 原生节点菜单、键盘、拖动、多选、复制粘贴、关联线、摘要、分支专注、布局、缩放、居中和全屏。手机用画布内“节点菜单”打开同一个原生菜单；节点编辑按钮不再放在画布外。树形层级和额外关联线分别保存。
- `graphics/mindmap-ui.js` 通过原生 API 扩展画布内节点属性、撤销／重做、多选和添加线索，不维护第二套树模型。属性包括字号、宽度、字体、颜色、分支颜色、标签、图标、网址、备注和本地图片；只应用实际修改的字段，保留未改动的继承样式及导入属性。原生布局工具条增加向下布局和适应画布，可访问名称和键盘操作同时补齐。未增加额外插件或修改上游运行文件。
- 工具结果可加入新建或已有图稿。文字在画面中预览前 3,000 字，完整来源字节独立保存。图片尾部数据不会因预览丢失；来源可下载，也可返回原工具。
- 笔记顶部直接提供“插入脑图”和“插入线索白板”，创建后归属当前笔记，无笔记时新建一篇。“返回笔记”先保存，正文的预览图、可编辑图稿链接及附件按钮可再次打开。正文也可送入图稿，图稿支持导出 PNG。脑图和白板编辑区不提供“用其他工具处理”按钮。
- 数据保存在原有本机笔记数据库，没有新增云账号、自动上传、多人同步或第二套数据库。

## 保存边界

`graphics/model.js` 是无 DOM 的格式边界。一个 `application/vnd.mist-drawing+json` 附件保存版本、场景及来源，配对 PNG 附件供笔记展示。笔记备份和自包含 Markdown 能包含这些附件。PNG 不能代替可编辑原稿。

`app.js` 将图稿页面挂入笔记本提供的 graphicsHost，并注入笔记事务服务；绘图页面不直接操作 IndexedDB 或 Vditor。打开图稿先对齐当前所属笔记。切换笔记清除另一篇笔记的画布显示，原图稿仍保存在原笔记；笔记与图稿间的导航在笔记事务结束后执行，避免队列互等。保存序列化，同时核对图稿修订和笔记乐观锁。保存失败保留草稿与导出入口，离开页面前保存。异步读取和提交工具结果都检查其有效性。

来源名称及路由来自当前登记任务，原生工作区按登记的控件映射读取当前方向，不假定原生控制器具备 CyberChef 的 getOperation 接口。笔记自身的事务结束后才发起图稿创建，避免同一队列自等待。Vditor 适配层识别普通链接、即时渲染链接标记和图片的资产 ID，再交给笔记页面打开原稿，不把可编辑附件当作普通下载链接。

保存失败可重试，或先导出草稿，再用“重新载入”明确放弃当前修改并读取已保存版本。脑图原生撤销、重做、紧凑布局和键盘深度折叠同样触发保存；原生操作事件及 refresh 边界共同识别文档变化，重复通知和临时视图不重复标脏。画布里的 Ctrl K 深度折叠组合键由编辑器接收，画布外仍保留网站搜索快捷键。手机工具栏完整换行显示。

节点样式、标签样式、备注、图片、分支颜色、紧凑布局、关联线和摘要随原稿保存并进入笔记备份；导入样式限制为安全的本地字体、颜色和数值，不能引入远程 CSS 资源。专注仅改变临时视图，保存始终取完整根节点及原方向；生成笔记预览时用短生命周期的离屏原生实例渲染完整文档，不改变当前选区或专注状态。原生摘要只能选择同一主分支内部的节点，选择中心或跨主分支时显示中文原因。

单图稿及来源最多 24 MB、2,000 对象／节点，脑图最多 60 层。单次图片 16 MB、3,200 万像素。只接纳本地 PNG、JPEG、WebP、GIF，不接受外部图片与嵌入网页。笔记原有 64 MB 单篇、128 MB 备份限制继续适用。

## 固定依赖

`upstream/graphics/package-lock.json` 固定依赖；`scripts/import-graphics.mjs` 从已安装的依赖离线构建 `public/vendor/graphics`，普通构建不安装依赖、不访问 CDN。Excalidraw 仅在共享容器中使用独立 React 根，不接管网站；Mind Elixir 原始分发字节保留。

`UPSTREAM.json` 保留输入／输出 SHA-256，运行包保留依赖、字体原始通知。字体获取地址、Git blob 和 SHA-256 在 `upstream/graphics/notices.json`，Excalidraw 主许可证来自官方 v0.18.1 标签。

公共编辑器主题在 `ui/components.css`，页面 CSS 只负责布局。编辑器装饰性 CSS 动效关闭，绘图及拖动保持即时响应。

## 定向验证

`tests/graphics.test.mjs` 覆盖格式、关系、安全资源、完整来源字节、备份和修订冲突。`scripts/browser-graphics.mjs` 使用真实编辑器检查绘图、脑图、工具结果联动、笔记预览／再次编辑、保存失败恢复，以及桌面、手机、子目录。共享导航、笔记、UI 与许可按测试计划选择对应契约。
