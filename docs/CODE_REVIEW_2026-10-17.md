## 审查范围与方法

全站检查从模块依赖、UI 所有权、来源许可和现有全部单元测试开始，再人工检查高风险边界：笔记存储与附件保真、编辑器净化与导出、图稿联动、任务生命周期、Worker 取消与结果发布、在线资料代理、邮件反馈和静态服务。针对确认的问题补可重复的回归，并修复拥有该行为的模型、适配器或服务。

这是本轮代码审查记录，不是安全认证或“全部代码不存在缺陷”的保证。第三方固定包检查摘要与许可，未逐行重审其全部源码；浏览器检查采用受影响专项及跨站关键路径抽查，未宣称穷举所有算法和操作组合。没有连接正式服务器、发送真实邮件或自动发布。

- 笔记、附件、白板与脑图仍保存在本机，未增加自动上传或第二套存储。
- 在线查询仍只请求已登记的固定来源；没有新增通用 URL 代理或自动抓取回退。
- 本轮未修改官方 vendor 字节、算法实现、来源条款及视觉风格。
- 静态目录真实路径检查防止意外链接泄漏，不应被理解为抵抗拥有服务器文件写权限的攻击者在检查与读取之间持续替换文件；生产部署仍需限制写权限。

- 没有做长时间、多 GB 笔记库存储压测；不同浏览器的配额、低内存设备承载量不能由本轮功能测试推定。
