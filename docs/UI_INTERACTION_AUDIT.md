# 共享交互重做与检查范围（2026-10-19）

本轮以 Animate UI 2.0.0 为控件与动效来源，运行依赖固定在本地，工具引擎和玩家数据继续由原控制器管理。

| 交互 | 本轮实现／修复 | 验证 |
| --- | --- | --- |
| 普通单选下拉 | 真实 Animate UI Select；浮层、滑动高亮、选中标记、键盘选择；支持动态参数选项与重复值索引 | 原值、单次 change、程序写入、禁用、隐藏、卸载；电脑／平板／手机与减少动态模式 |
| 弹窗中的下拉 | 随弹窗第一次打开接入，浮层挂在同一原生模态顶层 | Escape 先关下拉，父弹窗保留；方向键／End／Enter 更新原参数 |
| 弹窗／手机抽屉 | 直接导入 Animate UI 的 Dialog／Sheet 动效定义，由 Motion 执行；删除原内容 CSS 位移，保留原生焦点、inert 与顶层 | 快速关闭再打开、目录与抽屉互切、退出期间销毁、键盘缩小视口、实时减少动态 |
| 桌面侧栏 | 官方 slide 节奏同步页头和正文；品牌固定顶栏；实际复用 SidebarHighlight 同源的 TriggerHighlightScope/useTriggerHighlight | 四种侧栏视口／偏好组合，导航、过滤、输入保留；高亮独立宿主防止列表替换清理冲突 |
| 共享悬停 | 页头、工具栏及侧栏使用同一上游高亮；Shadow DOM 绘制层通过 slot 保留原按钮和列表结构，动画始终位于文字下方 | 连续跨项、首次输入后悬停、动态标签／列表、禁用、键盘焦点、实时减少动态及卸载清理 |

## 保留的明确边界

- 浏览器的文件选择器、颜色选择器和系统权限提示由浏览器绘制；没有伪造上传控件或权限弹窗。
- 多选或多行原生列表保留列表操作语义，不强行改成普通单选菜单。
- Vditor、Excalidraw、Mind Elixir 的内部编辑器由各自项目拥有；本轮统一的是本站共享控制及其与编辑器的入口、菜单和弹层，没有修改官方 vendor 字节。
- 模态框仍由浏览器维护焦点和页面隔离。复用的是 Animate UI 的真实动效源码，不额外安装第二个焦点锁或复制用户内容来做退出截图。
