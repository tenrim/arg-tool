# 工作台核心交互修正

本轮根据 2026-10-21 的实时单位换算、表单排布、计算器动效、鸟类字段、盲文键盘及最近使用反馈实施。保留此前所有未提交改动；版本仍为 V1.2，本轮未发布。

## 后续盲文按键精简

按用户后续要求，按键改为仅展示 26 个英文字母及有明确含义的数字标记，共 27 项，按 A–Z 排列后列出数字标记。空白与没有对应字符的点阵不再生成按键；原始逐点输入仍可查看全部六点组合，切换录入方式不替换未知图形或丢失当前点位。没有更改上游映射或引入另一套盲文表。

本次精简单独按 `outputs/braille-meaningful-20261021/files.json` 验证，不沿用下方前轮结果。

## 根因与所有者

- 公共 FormGrid 的 auto-fit 网格遇到完整行选项时保留了空列。复现时 1120px 表单分成七列，四个参数每项仅约 151px，文件按钮也挤在一个窄列。共享层改成按实际宽度换行的弹性行，完整行文件和复合参数有明确语义，标签换行不再推低其中一个控件。整数报告的相关开关合并为一个具名组选项。
- Animate UI 的悬停背景被统一施加到所有按钮父容器，二维键盘也会在不相邻键之间滑动。共享适配现在按真实排布区分线性／二维操作区；二维按键仍保留真实组件按压和悬停动效，各键独立反馈。ResizeObserver 与生命周期清理属于共享适配。
- 最近使用原来记录页面根 ID，使跨面板专题出现多个记录，也把共用面板的不同工具误记成一个。现在由 registry 解析真实成员，再投影公开工作区身份；会话记录保存最后打开的成员链接，不包含输入、文件或结果，旧偏好格式与校验保持兼容。
- 鸟类／音乐原始字段同时被当作主详情渲染。鸟类、音乐、星座及日月食模型现在提供常用字段投影，共享 RecordDetails 区分常用、补充和完整原始资料，完整字段、中文补充署名、来源、许可、元数据、工作簿和笔记租约保持原所有权。
- 盲文点位状态原来放在 app 装配层。已迁回符号控制器，以同一个六点选择驱动 有对应含义的字符键盘和逐点输入，默认字符键盘；没有为未知图形编造英文字母。

## 实时计算

liveCalculation 以修订号拒绝过期成功／失败，输入立即清空旧结果及笔记租约。连续键入以 120ms 短合并窗口减少重复计算，单位选择即时执行；正确性不依赖等待时间。空白、符号及未完成指数草稿不报错，组合输入结束后才计算。实时换算只接受数字，不提交赋值、自定义定义或文件；独立单位实例可以保持加载状态，停止、执行中编辑及离页终止旧工作。仍使用全部 452 个原单位定义，由真实 Qalculate 运算，不复制倍率。
