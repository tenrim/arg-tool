## 使用范围与真实边界

这里的“完整”指保留固定上游包及数据，并开放上述缺口中的原生能力；不等于把桌面软件、任意后续版本和所有可能的组合逐个做成专用表单。Astronomy、lunar、RDKit 的长尾接口使用可执行的 JSON 工作表，Tonal 与 cnchar 使用原生方法及 JSON 参数，而不是把方法目录或外链当成功能。工作表不执行任意 JavaScript，不能访问 DOM、主机文件或网络。

- SeqViz 不自动向 NCBI／iGEM 请求 accession，不下载远程字体；本机文件最多 2 MB，所选序列最多 100,000 字符，超限报错而不截断。回调、React 子节点及网站整体样式由本站控制。保留原文件的全部记录，不把第一条冒充整个文件。
- cubing 的求解仅限固定库实际提供的专用接口；3×3 接口不处理中心方向。没有原生求解器的谜题明确报错。公式展开上限 10,000 步，Worker 最多 60 秒。
- RDKit 是固定 MinimalLib 浏览器包，不是桌面 Python RDKit 的全部模块；分子报告最多 5,000 显式原子。原生工作表最多 128 条指令／16 MB 结果，超限明确失败，30 秒可终止。
- cnchar 的资源及图形均在本站本地；本地语音播放仍需浏览器允许；voice.speak 由浏览器合成，voice.regonize 使用浏览器语音识别服务，可能联网并发送麦克风音频，仅在明确选择并执行、授予权限后触发，界面有常驻说明。只读查询开放，不能通过原生方法入口改写全局资源地址或注入插件。普通汉字表单原有边界保留，完整记录区超过 300 字明确拒绝。
- StegOnline 数据嵌入沿用上游 RGB 支持范围，不虚构 Alpha 嵌入；载荷最多 1 MB，容量不够拒绝，不悄悄丢尾部。原始 RGBA 是浏览器解码像素，不冒称原 PNG 编码字节或 16 位原样恢复。
- FFmpeg 能力以此固定 WASM 核心的实际列表为准；没有编译进来的编码器、设备和系统硬件不会被冒充可用。仅访问虚拟文件及 pipe，多文件合计 32 MB，执行限时，禁止网络协议；完整日志上限 16 MB，界面预览上限不影响下载内容。
- CyberChef 官方 Worker 字节保持不变；单步按原输入执行到下一位置，完整输入仍保留原始字节；换输入／参数／配方、取消或离页作废旧结果。Magic 是推测结果，采用候选后仍需实际执行验证。

## 固定来源和离线重建

新增包原件、npm integrity、锁文件及提取内容位于 `upstream/completion-20261020/`。`scripts/build-upstream-completion.mjs` 离线构建 SeqViz、全量 Tonal 和本地汉字资源；SeqViz 维护依赖按该目录 `seqviz-build/package-lock.json` 固定，只有维护重建时需要安装。构建器复用既有 `upstream/graphics/package-lock.json` 固定的 esbuild 0.28.2；全新维护环境先运行 `npm ci --prefix upstream/graphics` 和 `npm ci --prefix upstream/completion-20261020/seqviz-build`，再依次运行上述两个脚本。普通网站构建不运行 npm 安装，也不联网取资源。`scripts/finalize-upstream-completion.mjs` 核验原始归档并只更新本轮声明的生成文件摘要。完整性审计同时检查汉字和 SeqViz 运行文件。

来源登记位于 `public/project-licenses.js`、`public/project-source-contracts.js`、`public/project-sources.js` 和 `upstream-manifest.json`；SeqViz 及间接依赖独立通知、cnchar MIT、字典 LGPL 与图形文鼎 APL 分开保留。对应工作区仍使用共享来源所有者，在实际页末展示来源。
