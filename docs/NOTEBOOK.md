# 本机笔记本

入口为网站页面 `#notebook`，不计入五类算法能力和科普数量。编辑器为固定 Vditor 4.0.0，默认即时渲染 Markdown；样式沿用工作台、字体与静态 CRT 扫描线。

思维导图和线索白板同属此笔记本。三个视图共用标题、笔记列表、当前笔记的图稿索引与使用说明，图稿编辑器嵌入同一页面；不再作为“其他工具”或独立工具目录项出现。路由为 `#notebook/mindmap`、`#notebook/whiteboard`，旧绘图路由归一到这里。切换笔记先保存图稿，当前笔记的列表不会展示另一篇笔记的画布；正文预览、左侧图稿索引、工具结果收录都打开同一份原稿。

## 使用

- 新建、改名、搜索、编辑；标题与正文自动保存。笔记列表上方直接显示“删除笔记”，删除前确认当前笔记名称及正文、附件、脑图和白板的删除范围。取消保留内容，删除后选中其余笔记，全部删除后显示空态；图稿视图先保存并返回笔记，再打开确认，不在笔记事务队列中等待图稿保存。
- 顶部统一“新建笔记 / 插入脑图 / 插入线索白板 / 导入·导出 / 使用说明”，可切换笔记、思维导图和线索白板视图；标题旁显示行内保存状态。正文工具栏负责编辑，大纲可收起，手机分屏预览按上下顺序排列。沿用无衬线工作台标题和 CRT 纹理。
- Vditor 三种编辑模式、标题/列表/待办/引用/表格/链接/代码、表情、缩进、插入行、撤销重做、大纲、全屏、字数、预览、代码配色、内容主题和语法检查均有入口。
- 本地 KaTeX / mhchem 公式、代码高亮；图表菜单支持 Mermaid、Markmap、ECharts、JSON 脑图、Graphviz、flowchart.js、WaveDrom、ABC 乐谱、SMILES。不是静态示意图；按正文实际渲染。
- 富文本粘贴先过滤再转 Markdown；文件支持粘贴、拖入和附件选择。更多菜单可录音，开始时才请求麦克风，取消/离页释放设备；音视频附件可以本地播放。
- 原生基础转换、CyberChef 单任务及完整处理链、图片提取／图片视图、文件原始字节和 ZIP 已提取条目共享“加入笔记本”。按钮只在其原控制器结果有效时可用。
- 收录时选择已有或新建笔记、记录标题、备注；多文件结果先明确选择一个。来源只记录工具名称和登记的任务路径，不记录输入、密码等参数。
- 文本使用围栏代码块，图片可预览，所有结果均保留原始附件字节。大文本作为完整附件，不将截断预览冒充结果。图片原文件与处理视图明确分别选择。
- 笔记页可主动添加本地附件；导出单篇 Markdown（附件使用内嵌数据），或导出包含全部正文和原始附件的 JSON 备份。Markdown 和 JSON 导入均创建副本，不覆盖已有笔记。
- 支持独立 HTML 导出（含公式字体、图表和附件，无运行脚本），以及浏览器打印/另存 PDF。
- 单篇正文 2 MB，单附件 32 MB，单篇合计 64 MB，最多 500 篇，单次备份／导入 128 MB。浏览器实际配额仍可能更小；失败明确显示，不谎报已保存。

## 数据与模块边界

- `public/notebook/model.js`：纯文档模型、限额、原字节收录、Markdown 围栏、完整备份校验。
- `store.js`：独立 IndexedDB `mist-notebook-v1` / `notes`，事务完成才报成功；乐观版本校验拒绝其他窗口的过期写入／删除；导入一次事务提交。
- `editor.js`：同源绝对资源路径、Vditor 初始化及销毁、附件 Blob URL 生命周期、DOMPurify 解析边界。只改预览副本的图表标记，源码围栏和正文不改写；切换模式后首次输入同步记录撤销基线；复制代码不依赖内联事件。
- `renderers.js`：图表适配层。ECharts / WaveDrom 使用 JSON.parse，拒绝脚本和资源 URL；Mermaid 使用 strict 和纯 SVG 文本标签；Markmap 关闭 Prism 的全页自动扫描及远程插件加载；SVG 仅保留本图内部引用。Graphviz 独立 Worker 限时并释放，图表销毁清理实例/观察器。
- `export.js`：完整附件和公式字体内嵌到无脚本 HTML。`recorder.js`：仅用户启动录音，限额和设备释放独立于编辑保存。
- `page.js`：共享组件组合、输入与保存队列、笔记切换、来源收录对话框、备份与错误状态。离页／后台主动保存，有未保存编辑时关闭页会触发浏览器原生提醒。
- `handoff/button.js`：命名的结果动作桥；同一读取闭包、有效性租约和原按钮启用状态供“用其他工具处理”“加入笔记本”使用。组件 mount/state/unmount 同步伴随按钮，移动原节点不复制工具结果、不导入笔记控制器。
- `app.js` 只注入导航和登记的当前任务身份；功能模块互不导入业务控制器。笔记不进入路由、工具偏好、收藏备份或故障报告。

笔记限当前浏览器与同一网站源，不是账户同步。清理网站数据会删除笔记；部署到不同域名／端口也不会自动迁移，请使用备份。隐私模式或存储被禁止时会显示错误，未落盘内容可从当前编辑页导出。

### 明确的接入边界

不启用远程上传、外链图片自动抓取、PlantUML 公共服务器、联网语音服务或多人协作服务。PlantUML 源码保留并明确提示，不能伪装为本地渲染。公式使用 KaTeX，不重复装另一套 MathJax。图表资源来自固定 Vditor 分发包，源码及许可原文完整保留；这些限制不影响 Markdown 导入、编辑和原始内容导出。

## 供应商与验证

固定 npm 依赖锁在 `upstream/notebook/package-lock.json`。维护时在该目录 `npm ci --ignore-scripts` 后运行 `node scripts/import-notebook.mjs`；普通构建直接使用 `public/vendor/notebook`，不下载 npm／CDN 资源。许可原文、依赖和复制文件哈希见该目录 `UPSTREAM.json`、`NOTICE.txt` 与 `THIRD_PARTY.md`。

测试所有者为 `tests/notebook.test.mjs`、`scripts/browser-notebook.mjs`，已登记到受影响计划和完整验证目录。结果桥另保留 handoff-feedback，共享壳与样式使用实际变更所选的 UI／导航回归。

## 可编辑图稿

“新建笔记”旁的“插入脑图”和“插入线索白板”直接在当前笔记中创建内容，没有笔记时新建一篇。正文预览图、可编辑图稿链接及附件编辑按钮均可再次打开原稿，编辑器的“返回笔记”会先保存再返回所属笔记。“导入 / 导出”内仍可把正文加入图稿；工具结果也能直接加入已有图稿。原有备份格式无需升级，完整备份包含图稿、预览及来源原始字节。详见 [GRAPHICS.md](GRAPHICS.md)。
