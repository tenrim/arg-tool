## 帮助折叠连续性修正

2026-11-04 用户反馈展开／收起有停顿。逐帧复现发现，原生 Disclosure 的正文外边距穿过 `::details-content`，没有计入过渡高度，展开接近结束时另跳 16px，关闭时也分段回收间距。公共动效样式给内容伪元素建立 `flow-root`，使正文及外边距共同参与原高度动画；保留原 Animate UI 派生曲线、时长和减少动态设置，不增加首页专用动画。
