# 查询类功能检查报告

检查日期：2026-11-10。检查开始时共有37个“资料查询”公开入口，同时纳入分类外的汉字反查、中英文查词、T9、网格搜词、乐理、DNS/HTTP及结构化数据查询。移除两项失效服务后，保留35个资料查询入口；在线查询保留7个来源、24种表单模式。编解码、媒体处理、代码运行和一般计算器不在本轮范围内。

本轮检查了每个查询入口、实际提供的模式、所选资料范围、代表性正确结果、有效输入边界、空结果、资料加载失败及恢复。固定资料的范围、字段和来源也进行了核对。这里的“通过”表示这些检查通过，不表示穷尽所有可能输入或外站永远可用。

## 按本轮要求移除的功能

正式网站实际查询确认SIMBAD和VizieR返回上游连接失败。按用户随后要求，移除这两项查询的前后端功能，包括导航、搜索、相关科普、关联入口和后端提供方；旧链接安全返回现有页面，不跳成另一项查询。

这项删除与本轮修复最初在本地完成；2026-11-10 随后获用户授权，已作为 V2.1 发布到正式网站，功能范围见 [V2.1 更新日志](releases/V2.1-更新日志.md)。原始来源归档、许可证依据与历史版本记录保留，不当成现行功能展示。

## 保留的资料边界与后续改进

- 本地资料是已标明版本的固定快照，未逐条人工更新世界上所有国家、机场、鸟类和作品信息。中文名称、历史关系及资料未收录项均不靠猜测补齐。
- 传统历法的公历和农历表单均限定年份1900—2100；边界公历日期可能对应1899农历年，因此该交界不承诺两种表单均可反查。
- SMILES原始质量值可能显示浮点尾数，例如苯显示`78.11399999999999`。结构和运算正确，但显示可读性仍可改进。
- DNS的外网超时保留为未通过项；未新增代理、偷偷切换来源或将超时当作查无记录。
- COD仍有间歇性连接问题。精确编号修复使用官方真实响应及回归验证；修复后本机联网重试失败，未宣称联网复测或线上修复已通过。
- cnchar逐笔分图的内部请求没有单任务取消接口。本站会结束等待、移除旧图并作废回调；已发出的原库请求可能继续到达，但不会恢复旧页面结果。本站拥有的预读请求会实际中止。
