# 计算器与单位换算界面调整（2026-10-21）

本轮按玩家的实际使用方式重新排布界面，不扩充另一个计算引擎。开始时工作区仅有未跟踪的 `outputs/`，现有内容保留。版本元数据仍为 V1.2，本轮不发布到服务器。

## 计算器

计算器独立显示为“综合计算器”，保留 Qalculate 搜索别名及旧链接。普通和科学模式共用一个包含算式、结果、内存与按键的计算器面板；等号为唯一计算按钮，仍可使用 Enter 计算、Shift+Enter 换行。科学函数、角度、精度及真实内核运算保留。

历史、设置、完整结果使用右侧标签面板；窄屏排在计算器下方。历史记录点选恢复算式，设置切换不复制输入节点。完整记录、生成文件、绘图、下载及笔记／图稿保存仍使用原始结果。科学按键的长函数名按可用宽度排列，不拆开显示。修改算式时同步取消旧运算和内存请求，旧请求不能再发布状态或结果。

参考原作者公开界面与使用文档：

- [Microsoft Calculator](https://github.com/microsoft/calculator) 的普通／科学模式、内存和历史布局。
- [Apple 计算器历史](https://support.apple.com/guide/calculator/see-previous-calculations-calceebf81c8/mac) 的侧边历史与复用算式方式。

保留本站海军蓝、琥珀色、青色和既有字体，不引入其他网页计算器。

## 独立单位换算

其他工具下增加“单位换算”分组，学科任务直接使用同一登记模型生成侧栏、工具目录、搜索和科普：

| 学科入口 | 对应物理量举例 |
| --- | --- |
| 几何与日常单位 | 长度、面积、体积、时间、频率、角度 |
| 力学单位 | 质量、密度、速度、加速度、力、压强、流量 |
| 热学与能量单位 | 温度、能量、功率、熵 |
| 电磁学单位 | 电流、电压、电阻、电容、磁场 |
| 光学与辐射单位 | 光强、照度、光通量、放射性、剂量 |
| 化学单位 | 物质的量、浓度、摩尔质量、催化活性 |
| 信息与印刷单位 | 比特、字节、容量、印刷尺寸、比例 |
| 货币单位 | 随包固定汇率单位 |

全部 452 项随包单位定义保留，按物理量选择，不另写倍率；前缀、复合量和温度偏移均交给真实内核。货币明确提示固定快照，不提供实时汇率。各学科保留自己的物理量、数值及单位草稿。新工作区独立拥有取消与记录租约，原 `topic:units` 链接归到日常单位。原 CyberChef 操作及 505 项来源覆盖保留。

新增的八个可见任务均有对应科普、真实内核实例、文献和精确来源页脚；换算工作区不误列未使用的 Gnuplot。

## 提示清理

计算、处理链、代码运行、图片、音频、视频、纸笔、棋谱、图集、资料查询、科学工具、时区、折纸与图灵机等实际控制器不再在普通输入、参数变化或离页时显示“已修改，请重新执行”类过程提示。清理发生在状态所有者，不通过隐藏旧错误来处理。

同步取消、旧结果清除、复制／下载禁用和笔记租约失效保留；真正的错误、读取或计算进度、主动停止、资源限额、固定汇率和联网去向仍明确展示。用户点击保存旧结果时的失效错误也保留，防止误存资料。
