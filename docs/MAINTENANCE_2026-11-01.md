# 迷雾工具箱代码整理结果

日期：2026 年 11 月 1 日。对应 V1.8 后的维护整理。

这轮按检查报告的七项建议进行了处理。重点是让后续修改更容易查找、更容易验证，保留已有功能和数据。

## 改了什么

| 原来的问题 | 这轮处理 |
| --- | --- |
| 已发布代码没有完整进入 Git | 将已发布实现和相关来源、测试整理成独立提交，核对 V1.8 发布清单中的 46 个文件；临时输出、私密文件和 Android 测试目录不随之提交。 |
| 测试依赖本机 16332 服务 | 五个测试改为自行启动临时网站，使用随机端口，结束后关闭自己的资源。换电脑或自动检查时不再依赖开发者已经打开的服务。 |
| 新旧文档混杂、规则矛盾 | 新建统一开发指导，简化根目录维护入口；118 份旧阶段文档和检查快照移入历史归档，另保留旧规则、旧边界及根目录报告原文。当前搜索、Desmos、媒体分工和版本来源已统一。 |
| 笔记和图稿文件太密集、职责太多 | 统一这部分代码排版；把备份／回收站、图稿导出设置分到专门文件，原笔记存储和操作队列继续共用。 |
| 公共样式内部混杂 | 分为 10 份有明确顺序的源文件，网页仍加载一个生成后的公共样式文件；自动检查阻止源文件与产物不一致。配色、扫描线和样式规则顺序保留。 |
| 页面间联动关系不直观 | 明确 29 类真实页面事件的发送方、用途、载荷和当前引用者，加入越界与遗漏检查。原报告中的第 30 项实际是启动性能标记，现已分开。 |
| 工具目录加载完整科普 | 工具目录和搜索使用从完整正文自动生成的轻量目录，打开科普后才加载正文；仍保留完整文章、全文搜索、成员实例和参考资料校验。 |

旧文档从当前指导入口清退出去，但没有删除历史依据。今后先看 [开发指导](DEVELOPMENT_GUIDE.md)；文件职责看 [模块边界](MODULE_BOUNDARIES.md)，详细约定看 [项目约定](PROJECT_CONTRACTS.md)。

## 验证情况

- 笔记管理已验证桌面与手机宽度；笔记链接、附件、历史恢复、数据库迁移和原字节保存通过直接回归。
- 图稿的透明导出、选区保护、素材库保存与恢复、切换后的撤销通过回归。
- 搜索默认排除科普、设置开关及刷新后保留通过回归。
- 科普验证了首页／搜索不请求正文、进入后完整阅读及文献、离页后拒绝迟到内容、重新进入和加载失败后的恢复。
- 相关模型、架构与 UI 规则检查已执行。旧测试中两类过时预期已改为当前明确规则：搜索默认范围、同一文献合并显示；原文、实例、具体来源与字段保留检查未取消。
- 公共样式标准化排版后，565 条浏览器解析规则及其顺序与整理前一致；按钮状态验证覆盖 1440、800、320px 和普通／减少动态模式。
- 当前及归档的 72 份文档、479 个本地链接通过检查；366 个第一方模块、887 条明确导入没有循环或禁止跨界。
- 固定第三方的 28,849 项来源／运行文件摘要和 151 项许可登记通过检查，离线构建成功。格式检查与生成物一致性检查通过。

本轮是针对实际修改的验证，不是每个工具逐项重新验收，也不是安全或性能专项。没有据此宣称启动速度提高了某个百分比。

## 后续维护时仍要注意

这次统一了最需要整理的笔记、图稿和公共样式，不代表所有历史源码都已重新排版或所有大文件都已拆完。未触及的旧源码按以后实际修改逐步纳入统一格式；不要为追求文件小而机械拆分。

公共样式内部仍保留现有层叠关系，事件也仍承担必要通知。现在这些关系有清单和检查，但不能把它说成“完全没有耦合”。以后修改某个模块时，继续在其所有者处修复，不新增页面专用补丁、第二套存储或未登记的全局通知。

本轮范围是代码维护与 Git 同步，不包含服务器部署。V1.8 版本号保持不变。
