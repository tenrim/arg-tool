# 新手操作流程修复记录

2026-11-03；范围为上一轮操作审查的 16 项，以及用户指出的搜索 URL 后仍须重新选择的问题。仅修改本地项目，版本号保持 V1.9。

| 问题                                 | 原因与本次处理                                                                                                                                       |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 搜索命中仍回到默认功能               | 专题默认 `variantId` 被点击事件当作显式选择，压过匹配操作；侧栏链接也未完整序列化搜索子功能。事件和链接共用成员选择优先级，保留操作、方向和 `view`。 |
| 用生活语言找不到工具                 | 只按工具名、别名及模糊距离匹配。增加材料与意图组合的有界检索扩展，例如图片＋隐藏、未知＋编码、声音＋长短音；保留匹配依据，不调用外部服务。           |
| Base64 重复解码                      | 输入方式中的 Base64 是额外预处理，名字没表达其含义。输入选项和旁边提示明确“先还原字节，再执行当前操作”。                                             |
| 错误输入仍显示成功                   | 上游默认允许过滤非字符表字符。保留默认语义，单独说明被过滤字符；二进制结果显示十六进制预览，不冒充可读明文。                                         |
| Magic 两个输入框                     | 共享原文本和任务输入同时可见。由原工作区搬动同一个输入节点，并按输入来源显示唯一入口；回到原分析工具仍保留原文本。                                   |
| Magic 复制出来是 JSON                | 报告整体数据与候选片段使用相同的“复制”概念。候选有“复制结果片段”和明确的处理链入口，全局按钮明确“复制／下载完整 JSON”。                              |
| 文本隐写的密码说明串到佛又曰         | 共用模板写死算法专属说明。按实际引擎提供密码说明，并为承载文本补齐名称和有效示例。                                                                   |
| AES 错误难懂                         | 引擎错误直接作为唯一反馈。显示可操作的中文解释，标记对应字段，完整原始错误可展开；不把任何解密失败都断言为密码错误。                                 |
| 初次首页空收藏／历史占位             | 空集合也绘制卡片。仅有内容时展示，增加按线索材料开始的入口，沿用原能力登记与路由。                                                                   |
| 首页三处搜索争抢注意力               | 首页、顶部和侧栏都暴露完整输入框。保留顶部主搜索，首页目录保留分类浏览，侧栏筛选按需展开并明确范围。                                                 |
| 必要指引全藏在帮助中                 | 原规则把短输入要求和长帮助混为一类。相关控件旁保留必要提示；Base32、Base64、ROT13、Magic 可显式填入公开示例并恢复默认参数。                          |
| 扩展参数挤占首屏                     | 原始参数表直接平铺。Base 系列、Magic 和 AES 附加参数按用途折叠，显示当前配置状态；原参数控件、索引与草稿不变。                                       |
| Magic 左侧长时间留白                 | 固定两列承载短输入和长分析报告。生成候选后结果占完整工作区宽度，统计依据和完整参数按需展开。                                                         |
| 手机上运行后找不到结果／浮动按钮遮挡 | 结果位于输入下方，缺少明确定位动作及底部避让。增加由结果状态控制的“查看结果”，减少初始输入空行，为常驻笔记按钮留出底部空间。                         |
| 文件提示重复                         | FilePicker 和文件工作区各自显示文件状态。已有状态所有者的选择器关闭重复文件名提示；版本比较同时显示已选数量和文件名。                                |
| 空笔记页满是管理控件                 | 未区分空集合、活动笔记与正常列表。空态提供新建／导入，隐藏无对象的筛选／管理；回收站始终可进入，创建后恢复原管理功能。                               |
| 生活计算小数过多                     | 计算数值和主要展示用同一格式。主结果约四位有效数字，完整计算精度可展开，复制和下载保留完整数值、条件、公式与来源。                                   |
