# 能力目录与工作区架构

## 2026-10-14：统一任务入口

用户明确取消聚合工具页及旧链接兼容要求。工具页面只能以登记的具体任务打开；首页、分类总览、全部工具目录和科普目录保留浏览职责。删除任务内旧分类菜单、搜索、操作列表和处理链上的重复目录，不以 CSS 隐藏旧页面代替删除。

`app.js` 是任务路由的唯一激活者；`capabilities/task-selection.js` 将收藏、最近使用和启动偏好的页面 ID 解析为本次会话最近任务或登记中的默认任务。记忆只包含任务 ID 和方向，输入、文件、参数及结果仍由原控制器持有。未登记路径进入工具目录。任务内部方向切换与从目录选择同一方向共享参数兼容规则，切换时立即取消旧运算并作废结果。

验证范围遵循 [TESTING_POLICY.md](TESTING_POLICY.md)：日常只测受影响契约；本文列举的是保留的覆盖能力，不是每次改动的执行清单。完整检查使用 `npm run verify:all`。

本文记录正式工作台的信息结构和开发契约，与 [UI 开发强制规则](UI_DEVELOPMENT_RULES.md)、[通用 UI 组件](UI_COMPONENTS.md) 一起执行。功能数量从当前登记生成，旧工具页面数量不等于能力入口数量；本轮实际测试结果只以根目录 `VERIFICATION.md` 和本次报告为准。

## 五类与能力组

| 稳定分类 ID | 用户名称 | 能力组 |
| --- | --- | --- |
| `codec` | 编解码与加解密 | 字符与数字、通用与传输编码、符号与通信编码、古典密码与密码机、现代加密、签名／口令／密钥、密文识别与分析、文字／语言／提取、数据格式与排版 |
| `reference` | 资料查询 | IT 固定资料、国家／货币／交通、天体目录与观测、元素／物质／生命、字符与信号对照、颜色与色名、日期与传统历法、地质年代、八卦与塔罗、整数数列资料 |
| `media` | 图片音视频与文件处理 | 图像编辑与分析、碎片拼接、文件／字节／压缩、声音与音乐、视频与动画、三维模型观察 |
| `other` | 其他工具 | 棋谱复盘、纸笔逻辑、交互模拟、代码与计算模型、数学／单位／生成器、生物序列处理、坐标与时间换算、网址与网络数据、CyberChef 完整处理链 |
| `knowledge` | 科普 | 编解码与加解密知识、资料查询知识、图片音视频与文件处理知识、其他工具知识；主题沿用对应工具组 |

大类用于回答“从哪里开始”，能力组用于说明“这里能做什么”。用户明确新增科普后，五类约定替代此前四类约定。分组名称、顺序、用途、代表入口和数量由统一登记产生，不允许首页、侧栏、搜索和任务选择各自维护分类表。跨类别相关能力通过关联入口连接，不复制运算引擎或资料快照。资料查询保留固定数据库与真实记录；科普解释这些工具涉及的知识，不替代查询或运算。

## 渐进浏览

- 分类总览同时展示全部能力组。每组直接列出能代表不同用途的少量入口，并显示真实总数；不能只展示第一种编码、默认算法或单一资料。
- “全部 N 项”在该组内展开完整紧凑列表，其他组继续可见。展开只改变浏览量，不改变分类、不跳转新的层级页面。
- 完整目录提供搜索、五类筛选和组索引。定位一个组或一个任务只需这一层；搜索默认覆盖五类，不随当前工作区偷偷缩小范围。
- 中文名称、英文原名、专业别名和玩家常用描述共享同一匹配模型。搜索、代表入口及完整列表必须到达同一个真实任务。
- 进入任务后，工作区只保留当前路径、必要任务选择、帮助、参数／输入／结果，以及返回能力组和全部功能入口。不要在任务顶部再次铺开完整分类树。

侧边栏是正式导航的一部分。桌面保留可收起的常驻侧栏；手机使用同一个侧栏节点的原生抽屉，不能重建控件或创建第二套目录。打开／关闭导航、变更宽度或访问网站页均不得清除工具的输入、文件和监听器。首页只保留已收藏、最近使用、工具导航。

侧栏大分类名称打开分类总览，旁边独立按钮只展开／收起分类。多工具组在侧栏内展开真实功能链接，不再跳转组总览；只有一项功能的组直接显示该工具。点击具体工具或科普条目一步进入真实工作区／正文。侧栏搜索直接显示按统一相关度排序的任务与文章，保留明确的编码／解码方向；清空搜索恢复原展开状态。长列表按需分批呈现，当前功能高亮采用能力 ID，不能把同一页面内的所有操作一起选中。旧组总览深链接继续兼容，但不作为侧栏具体条目的目标。

## 统一登记与兼容入口

`public/capabilities/registry.js` 将现有原生工具和 CyberChef 操作映射为可发现的能力记录。记录包含稳定 ID、所属组、中文名称、搜索别名、原始来源工具 ID／操作 ID、执行边界及相关能力。代表入口、计数、目录与搜索由这份记录派生；新工具先登记再组合页面。

非空搜索在同一 `searchEntries` 中稳定按相关度排序，精确名称／操作及具体标题匹配优先于宽泛分组词汇；再交给各界面的既有展示上限。不能只测试完整匹配集合存在，必须验证精确命中在真实展示范围中可发现。分类过滤与原方向意图保留，空查询继续采用库存顺序，不变更登记对象。

| 文件 | 归属 |
| --- | --- |
| `public/navigation.js` | 共享静态分类／能力组定义与旧工具／网站路由 |
| `public/capabilities/registry.js` | `createRegistry`／`loadRegistry`／`searchEntries`／`resolveCapability`；真实原生目标、统一配对、`byOperation` 操作归属、`aliases` 旧单向入口、可见计数、科普关联与来源覆盖 |
| `public/chef-tools/families.js` | `operationFamilies`／`matchFamilies`；从统一登记投影原工具选择、CyberChef 索引与处理链选板，不拥有另一份配对表 |

| `public/capabilities/workspace.js` | `capabilityRoute`、当前任务外壳、返回组与全部功能 |

| `public/knowledge/page.js` | `mountKnowledge`；公共组件组成的搜索、领域／主题筛选、文章阅读与真实工具关联 |

可见组的 `entries`／`entryIds`／`count` 与 `representatives` 只包含已开放能力，完整库存另保留来源记录用于审查。同类型的两个真实方向只计一个功能族，底层操作覆盖仍逐项审计；不能把功能族数量与上游操作数量混为一谈。任务路由只携带原路由、稳定能力 ID、明确操作 ID 或原生方向 ID，不携带线索；收藏仍使用旧受校验工具 ID。

登记必须检查唯一能力 ID、明确组归属、原始工具覆盖和每个上游操作唯一归属。缺项或多归属立即报错，不能默默塞进“其他”。上游目录的流程控制、保留或未开放快捷入口是来源清单的一部分，不能因覆盖统计而冒充可独立执行的工具；图片 OCR 等用户已删除入口继续保持删除。

旧 `#crypto`、`#encoding`、`#image` 等页面及 `#panel/group` 深链接仍指向原算法和参数；原始 CyberChef 操作名、参数值与配方格式保持不变。功能 ID 与兼容工具页面 ID 是不同身份：收藏、最近使用、启动偏好和设置导入／导出沿用受校验的稳定工具 ID，不因新能力名称丢失旧数据，不把私密输入塞进路由或偏好。

同类型已支持的加密／解密、编码／解码登记为一个功能族，在工作区明确选择真实方向。`CHEF_OPERATION_PAIRS` 是 CyberChef 配对的唯一声明，原生转换在所属能力的 `nativeDirections` 登记；`byOperation` 让每个原始操作找到唯一能力所有者。`chef-tools/families.js` 投影可见功能族，`chef-tools/inverse.js` 从统一配对声明派生反向映射。完整处理链仍能添加每个实际操作，配方、运行时与来源覆盖保留原始 ID。

`aliases` 将旧单向能力 ID 映射到统一能力及原操作／原生方向，所有路由入口通过 `resolveCapability` 校验。旧解码／解密链接必须打开原方向，明确方向的搜索也不能落回默认编码。方向按钮保留源输入，立即取消旧执行、作废结果，只转移兼容的具名参数，并保留各方向独有草稿；“反向处理结果”及“继续处理结果”共用显式采纳所有者，保存真实字节与已执行操作／参数快照；进入明确逆向时按来源输出／输入格式初始化目标输入／输出。普通输入不猜格式，外部采纳清除旧归属，用户后续编辑不重复初始化。不得按参数位置复制不同定义，不给哈希、统计、签名／验签和有损编辑推测逆向，也不承诺任意输入无损往返。

## 科普内容与关联

每项真实可见功能独立一篇，编码／解码功能族只需一篇。正文分片在 `public/knowledge/articles/`，`content.js` 校验稳定 ID、唯一 `capabilityIds`、机制段落、实例与文献。数量从可见功能和内容派生，禁止按组补一篇概论充作覆盖。每篇包含输入单位、具体映射／运算规则、演算或结构例子、参数和边界；资料查询也解释该功能的编码／结构／读法。

每节 `sourceIds` 引用文章局部 `sources`，来源包含真实 URL、机构、文献标题、章节、语言与资料性质。先找国内官方中文文档及国内原始标准镜像；仅有原文则标注语言。引用必须支持对应细节，不能仅贴泛文档首页。原始实现与公开标准可能不同，需按固定版本核对，不把上游简介的错误当规范。具体要求见 [科普内容规则](KNOWLEDGE_CONTENT_RULES.md)。

登记根据文章 `capabilityIds` 建立每项功能唯一的 `learningIds`；错组、不存在的功能、重复覆盖和缺文章都直接报错。`relatedIds` 解析真实目标及原工具方向别名。旧分组科普及其 `learn:<旧文章ID>` 兼容映射已按用户要求删除；只登记逐功能文章，标题只用基本名称。文章链接为 `#knowledge?task=learn:<articleId>`。

阅读页同一文档挂载 `#panel-knowledge`。目录提供正文／文献搜索、四个工具领域与主题筛选，桌面目录／正文并排，手机切换并恢复焦点；ReferenceList 将文献置于对应正文和例子旁。重入同篇保持原节点，异步关联校验修订号并在取消／销毁后拒绝旧回调。阅读目录不采集用户输入，不以示例代替用户结果。

文献引用与软件依赖分别管理：引用标准／文档并不意味着集成其代码，也不生成浏览器 API 或本站仓库的虚构依赖页脚。实际复制的第三方文字、数据或图像须遵守具体许可；原查询工具和已集成引擎的许可与出处继续保留。

## 各类工作区的数据归属

| 工作区 | 共享内容 | 独立保留的模型 |
| --- | --- | --- |
| 文本／编码／密码 | 用户明确提供的文字或原始字节、兼容参数、真实方向 | 各操作参数定义、输入格式、输出类型与限额 |
| 国家／货币／交通 | 已选择的国家／地区对象及相关查询上下文 | 每个资料库的精确记录 ID、筛选、分页和固定资料范围 |
| 天体／观测 | 真实目录对象，以及用户设置的时间与地点 | 目录固定坐标和 Astronomy Engine 观测计算；无坐标对象不得伪造零值 |
| 其他资料 | 可视索引／目录与一个当前详情 | 卦象、牌面版本、字符码点、年代层级、序列大整数及实际 CIF 结构 |
| 图片／音视频／文件 | 当前用户素材、文件属性、当前预览与明确后续处理对象 | 原始文件和处理结果分离；照片隐写不能被重编码预览覆盖 |
| 棋谱／网格／模拟 | 公共标题、状态、工具栏、视图布局与导航 | 围棋和国际象棋规则、题型约束、生命游戏、魔方、图灵机及各自撤销／单步模型 |
| 科普阅读 | 统一主题组、搜索、文章与关联能力 ID | 有原始依据的逐功能正文、阅读选择及焦点；不采集工具输入或把科普示例当作用户结果 |

资料页应使用适合资料的图形或索引浏览，点选显示当前真实记录，并从同一个记录模型进入关联操作；不要把所有资料强制转成同一种输入表单。矿物进入现有三维观察使用真实 CIF 展开结构，不另开页面。详情、完整结果和后续任务来自当前查询对象，不能留下另一个旧对象的成功状态。

输入归属于原控制器或素材模型，公共任务外壳只连接与移动原节点。换任务可以保留适用的输入；旧结果、执行状态和异步回调必须按任务修订号作废。下载、复制和继续处理仅使用当前真实结果，不能从截断预览、展示 HTML 或格式化文本重建二进制数据。

`createInputSession()` 通过原控制器的读取／采纳接口共享适用输入，保留源类型：十六进制和 Base64 编辑内容不能冒充普通 Unicode 文字，文件与明确续接的原始字节不能自动解码。原生转换仍受自己的输入限额约束。媒体 `getMaterial(kind, source)` 的读取在异步导出前后校验原素材与修订号；切任务只选择控件，不能悄悄把预览替换为原文件。

载入引擎与载入目录也属于异步任务。深链接载入失败必须显示可见的恢复入口，不能让所有页面隐藏后只留下未捕获异常。处理链 `openRecipe` 在等待引擎后检查请求归属、输入／配方修订和当前路由；已离开任务或出现更新编辑的旧请求不得回填内容或抢回导航。分类任务使用原地载入方式保留当前能力路由。

科学与资料查询通过共享 `mountTaskLifecycle` 登记取消、超时清理和卸载行为。同页面的任务身份变化也必须作废旧输出；关联资料预选只能在实际目标页面进入后启动，不能在隐藏页面提前计算。保留原输入与对象上下文，使用修订号拒绝已排队的旧回调。

## 组件、动效与生命周期

页面只从 `public/ui/index.js` 使用公共组件与控制器；共享任务外壳也是组件组合，不能绕过工厂或写第二套控件。公共外观与动效只由 `ui/components.css`／`ui/motion.js` 拥有。地图、棋盘和 Canvas 等专用图形仍属于工具渲染层。

桌面按可用宽度提供输入／结果或浏览／详情的并排布局；手机自然堆叠，正文不裁切，内部长表格有界滚动，操作可触达。所有正常操作目标至少 44px，搜索与弹窗适配键盘可见视口，键盘操作和焦点顺序完整。

动效必须可中断、支持实时减少动态效果；状态、焦点、取消和输入作废立即完成。连续搜索、拖动、运算进度不反复播放进入，不克隆私密内容作退出动画。原生弹窗关闭同步恢复焦点；搬动侧栏或工具节点不丢文件，确实卸载时清理 Worker、事件、观察器和动画。

## 隐私、来源与验收

正常运算继续本地执行，重构导航不会添加上传、外部嵌入或远程执行依赖。仅用户明确选择的 HTTP／DNS 等联网操作发起对应请求。各任务使用原引擎、原限额、超时、取消与失败恢复，不能为统一 UI 降低边界。

中文使用说明放在共享帮助区；工作区保留真实状态和必要的数据限制。实际第三方项目、数据和素材的具体用途、链接及精确许可证在工具页最后呈现，关于页保留完整登记；纯本站代码、浏览器接口和空来源栏不展示。移动或合并任务时不能丢失来源归属。

新增回归登记到测试映射及 `npm run verify:all`，至少验证统一登记无缺项／重复、五类全局搜索、每组就地展开、旧深链接／收藏／偏好兼容、侧栏／抽屉、真实任务输出、跨任务输入与结果作废、资料详情联动、原始媒体保留、正常／减少动态效果、键盘和多端布局。功能族验证逐项操作覆盖、旧方向别名、双向实际运算、具名参数及源输入保留；科普验证逐功能唯一覆盖、正文演算、逐节文献、安全链接及精确关联能力、阅读焦点和过期回调拒绝。固定上游摘要先验后构建；已有引擎、许可、安全与隐私回归保留并按实际影响选择。只有本轮实际运行可以写入通过记录，原型示例和浏览器模拟不能代替生产运算或实体设备验收。

## 原生文件编辑与 IT 固定资料

十六进制编辑登记为 `native:hex-editor`，属于 media/files；继续使用 `#panel-file` 和唯一 `#file-input`。公共上传、统计和加载状态是文件所有者，分析／编辑视图仅选择同一素材，不能复制上传节点或把错误藏进未选中的视图。编辑器的原始／工作字节与文件分析素材分离，只有用户明确采纳时才交接快照；交接验证操作归属、路由和文件代次，不重新异步读取人工 File。离页立即停止搜索，恢复视图保留内存修改，卸载释放全部缓冲。

IT 查询登记为 reference/technical 的六项原生能力，同一 `#it-reference` 通过可见标签展示资料类别。标签选择同步真实能力深链接和页头，内部范围筛选由数据的 group 派生，不能重新维护一份资料类别清单。原始来源在 upstream/it-reference，离线生成先验证固定哈希；派生运行文件与许可声明纳入完整性审计。精选 RFC 必须保存源索引的状态和更新关系；多行记录不能截成第一行或把解析失败显示为“无”。普通构建不联网。

输入／输出格式在双向算法中分别描述明文侧与密文侧，是方向独有参数；同名、同类型不代表同语义。普通切换保留目标方向的草稿或真实默认值，Key／IV／Mode 等相同角色参数才共享。显式结果采纳的格式初始化使用已执行快照，不能用未采纳的预览或当前参数推断。回归必须覆盖首次加密／解密默认格式、目标手改格式往返保留，以及 Unicode 结果续接的独立密文与原字节对照。
