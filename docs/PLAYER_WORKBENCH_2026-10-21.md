# 玩家工作区完善（2026-10-21）

本轮目标是把已有引擎变成方便玩家操作的工具。2026-10-20 的全接口接入报告保留为历史快照；不再用原生方法和 JSON 编辑器代替玩家界面。

| 工作区 | 本轮处理 |
| --- | --- |
| Qalculate | 普通／科学按键、选区函数、角度、内存、上次结果、键盘；分类选择完整单位目录、交换单位；原生目录和高级定义折叠保留 |
| 旧单位换算 | 长度、面积、质量、速度、数据容量的独立入口继续由 Qalculate 承接；原 CyberChef 操作和全部 505 项来源覆盖不变 |
| 魔方 | 合并为一个工作区，包含全部 21 个固定形状；转动视角、原生二维／三维、起始公式、逐步观察、手动追加、观察记录；删除求解与竞速打乱 |
| 汉字 | 字形、逐笔、笔顺、释义、组词；完整笔画与字典可展开；移除公开原生方法、语音、姓名／随机和练字模式 |
| 乐理 | 音程与按半音移调的具体表单；原有音名、频率、和弦、音阶保留；移除专业模块／方法与 JSON 编辑器 |
| 序列 | 位置标记、搜索、错配数、正反六阅读框与线性／环形表单；原始文件、全部解析序列和原注释可完整下载 |
| 化学 | 符号拆分、分子式计数、结构图与常用标识；元素常用字段在前、全部原始字段可展开；专业指纹／反应／库管理退出正常界面 |
| 天文／历法 | 方位、升落、月相和全球事件保留；增加当地日食表单和星座归属，佛历／道历为可选文化参考；撤下泛用原生工作表 |
| 二维码 | 常用修复保持直接操作，码字编辑及完整分块诊断折叠为进阶内容 |
| 图片隐写 | 原始调色板与 RGBA 导出直接可用，文件／图片嵌入移至进阶区 |
| 视频 | 常见视频／音频输出格式直接选择，完整时长交给真实 FFmpeg；命令和核心能力保留在进阶区 |
| 其他 | 纸笔规则求解、代码／反混淆、棋谱、折纸、生命游戏、三维文件观察和完整资料集继续保留；既有低相关 CyberChef 原语仍仅用于配方 |

WebM 默认使用当前固定核心实际验证通过的 VP8／Vorbis。该核心的 VP9 预设实测触发 WASM 越界，未将它作为可用的便捷预设；原生命令出错如实提示，原始日志保留。

没有新增带单位数量的公式计算表单，没有接入外部 Qalculate 网页版。魔方记录由公式重算，尚不是任意题面照片的自动识别或手工涂色求合法状态功能。固定包中仅支持二维的形状如魔表、Square-1、Redi Cube、四维投影、Tri-Quad、Loopover 使用二维，不虚构三维能力。

单位接入修正了内部目录名称与实际输入语法混用的问题：如 `km_p_h` 不是可直接计算的单位拼写。生成器从原始 XML 展开前缀和乘幂，如 `(km)*(h)^(-1)`；不自行实现倍率，全部换算仍由 Qalculate 完成。映射涵盖完整实际目录，并保留固定源码摘要、生成器、许可和 notice。

本轮修改前保存了工作区状态和原有源文件备份，证据位于 `outputs/player-workbench-20261021/`。未重置、清理、提交或推送既有改动；未部署。验证结果在实际执行完成后补入下方。
