# UI 开发强制规则

验证范围遵循 [TESTING_POLICY.md](TESTING_POLICY.md)：只检查本轮改动及直接受影响的行为。本文列举的是保留的覆盖能力，不是每次改动的执行清单；自动计划仅提供候选，小改动不强制运行计划或整套专项。`npm run verify:all` 仅用于明确的全量任务。

适用于所有新工具、现有页面和共享组件改动。根目录 [AGENTS.md](../AGENTS.md) 要求先读此文；接口见 [UI_COMPONENTS.md](UI_COMPONENTS.md)，目录与工作区契约见 [CAPABILITY_ARCHITECTURE.md](CAPABILITY_ARCHITECTURE.md)。这些约定同时由源码检查、构建、浏览器回归和 CI 执行。用户明确改变产品要求时更新规则及检查，不能为通过测试而加入页面豁免。

## 组件与职责

1. 页面只从 `public/ui/index.js` 导入公共工厂、组合接口和控制器。初始页面也从该入口挂载。新增通用行为先实现为共享组件，页面只组合组件、连接数据和专用图形。
2. 常规 HTML 由真实组件工厂或 `render` / `insert` 创建。禁止页面调用 `createElement`、写 `innerHTML` / `outerHTML`、`insertAdjacentHTML`、`createContextualFragment` 或 `new Option`。补 `data-ui` 不构成组件实例。
3. `ui-theme.css` 维护配色和字体，`ui/components.css` 是最后载入的公共外观、状态、尺寸和动效层。工具 CSS 只定义布局与图形，不自行覆盖组件边框、字号、颜色、焦点或复选框排列。公共默认定位使用低优先级，不能覆盖已有 sticky / fixed。
4. Canvas、SVG 几何和计算引擎属于工具渲染层；不可信 SVG 必须走独立白名单，不得借用图形命名空间绕过 HTML 工厂。保持固定上游运行字节、原始来源及许可证。
5. 壳层负责导航、页头、收藏、搜索和帮助。新页面必须登记统一目录，提供中国用户能读懂的名称、图标和使用说明；引入第三方代码、数据或素材的工具，页末必须列实际项目及精确许可证；纯本站实现与网站页面不添加来源栏。浏览器接口与 MDN 不是项目来源，不保留空标题或原生接口占位；来源归属由 project-sources 在依赖组合完成后统一处理。不得增加额外窗口、iframe 或第二套导航。
6. 网站级首页、关于、设置与工具目录分开登记，默认进入首页，工具深链接优先。首页与弹窗目录使用同一 ToolCard；设置由共享组件与动效层应用，不给单页设置视觉补丁。偏好只持久化合法选项和主动收藏，最近使用只在会话内记录；选择上次工具作为启动页时才保存一个工具 ID。导入先验证完整数据，失败不得部分覆盖；备份不包含工具输入、文件、结果或草稿。

## 能力发现与工作区

- 正式五类：编解码与加解密（`codec`）、资料查询（`reference`）、图片音视频与文件处理（`media`）、其他工具（`other）、科普（`knowledge`）。用户明确新增科普后，此约定替代此前四类约定。公共分类／能力组定义与旧兼容路由在 `navigation.js`，真实任务归属在 `capabilities/registry.js`；首页、侧栏、总览、目录和搜索从统一登记派生，不各自维护标题、数量或别名。
- 分类总览直接显示全部能力组，每组展示能代表不同用途的少量功能和真实数量；“全部 N 项”就地展开完整列表，其他组保持可见。完整目录只保留一层搜索、分类筛选与组索引，不把未知功能藏在多级下拉菜单里。
- 全局工具搜索默认覆盖五类，中文名称、英文原名、专业词及玩家描述统一经 `searchEntries`／`capabilities/search.js`。固定本地 Fuse.js 7.5.0（Apache-2.0）在精确匹配后补模糊候选，保留明确方向和相关度优先；只索引公开目录元数据，不索引玩家内容、不调用外部搜索服务。代表功能、搜索结果和完整列表到达同一个真实任务。
- 顶端查找使用原位 Input／SearchField 与非模态候选浮层，禁止点击后再弹出搜索模态框或复制第二个搜索输入。保留 Ctrl／⌘+K、上下键、Enter、Escape、中文输入法、外部点击关闭、焦点与卸载清理。完整工具目录可保留其独立导航界面。
- 保留桌面原侧栏与手机同节点抽屉。任务页不再生成顶端分类面包屑、同组 peers 横排和原生方向按钮；标题、收藏、相关科普、使用说明及返回组／全部功能集中在共享页头，相关科普与使用说明位于同一 `.heading-actions`。原表单和参数／输入／结果保留真实节点，桌面充分利用宽度，手机自然堆叠。
- 侧栏大分类名称到总览，独立展开按钮只控制列表；组内具体工具／科普直接到工作区／正文，单工具组不再增加中间层。侧栏搜索直接输出真实任务链接，保留方向与排序；分组只在侧栏展开，不导航到组总览。所有列表、数量、链接及当前能力来自登记，不另建默认工具映射。
- 导航层只连接或移动原组件，保持原引擎、参数值、文件和监听器。旧深链接、工具收藏、最近使用与设置格式继续兼容；不能将新能力 ID 直接替代原受校验工具 ID，不能把输入或结果放进偏好。
- 同类型已支持的加密／解密、编码／解码必须登记为一个可发现的功能族，真实方向只在原表单／ConversionLayout 的 Select 中选择。`operation-pairs.js` 独占 `CHEF_OPERATION_PAIRS` 声明，registry 重新导出，并拥有原生方向、操作归属 `byOperation` 与旧入口 `aliases`；原工具选择、CyberChef 索引和处理链选板通过 `chef-tools/families.js` 从该登记派生，不再维护配对或逆向清单。原配方仍保存全部原始操作 ID，数量区分功能族与底层操作，不能通过删除解码操作减少重复。
- 同一具体用途／对象的碎片任务按 `capabilities/topics.js` 合并专题；`topic-model.js` 纯投影生成 `actions`／原生 `variants`、完整来源操作和别名，最终目录从 registry 派生。专题表单允许一个有明确名称的实际操作／变体选择，替代旧版禁止任务内操作选择的约定；不恢复全站分类／搜索选择器、整组泛总览或第二套页面。每次切换保留原控制器输入、文件和各成员独立参数草稿，同步取消并作废旧结果；只有原真实逆向对可共享语义兼容的具名参数，同属专题、同名 Key／Input 不能据此共享。
- 跨实现专题使用真实 `mixed` 成员，各自激活原 `open` 与控制器；原生 ID、原始 `op:` 别名、明确搜索和成员深链接必须到达对应实现。Base 家族、数字与字节、字符编码与码点、文字转义和二维码按此约定收拢，不以一套 UI 假装接口相同。整体整数换进制与逐字节编码不可混同，图片原文件、当前视图、修复矩阵与生成内容不得自动互相覆盖。
- 旧单向能力 ID 用 `resolveCapability` 解析为功能族及原操作／原生方向；明确搜索某一方向时仍到达该方向。切方向同步取消旧任务、作废旧结果，保留原输入与方向独有的参数草稿，只共享兼容具名参数。只有“作为输入”显式采纳真实结果字节和已执行操作／参数快照，随后再选方向；方向选择不能自动替换输入，不恢复反向快捷按钮。首次进入明确逆向时以已采纳来源的输出／输入格式初始化目标，仅接受两边声明的兼容格式。外部采纳清除旧归属，不按当前表单猜格式，也不重设用户后续修改。不给哈希、有损清理或签名推测逆向，不承诺所有双向操作无损往返。
- CyberChef 完整处理链在侧栏、目录及计数中只有一个入口；10 个流程控制和 `operation-policy.js` 新增 78 个 `recipe-only` 保留为配方内部真实操作，不另建工具、推荐或独立科普，5 个 retained 边界不变。全部 505 项的原始 ID、参数、引擎和唯一来源覆盖保持完整。Alpertron 仅启用 integer，退役高级方程／幂和等计算器不得从完整上游归档重新出现在菜单、联动或表单中。
- 资料页使用真实索引与当前详情对象，联动使用该对象；媒体保留原始文件与当前结果的区别；棋谱、网格和模拟共用组件外壳，各自的规则、状态、撤销与单步模型独立保留。不能为统一布局将这些模型强制改为同一种表单。
- 科普独立于资料查询，每项可见功能一篇（双向功能族一篇、专题一个入口），禁止工具组概论充当具体功能科普。`knowledge/articles/` 保存成员内容，`knowledge/topics.js` 纯投影合并专题；每个成员的准确步骤、输入单位、完整实例、参数边界和逐节引用均须保留。`content.js` 校验与冻结，数量从实际登记派生，不复制另一份分类。文章以 `learn:<articleId>` 登记，`capabilityIds` 建立精确且唯一的工具关联。每节 `sourceIds` 引用支持其机制的权威资料；文献 ID 去冲突后同步重映射，不能合并时丢引用。配方专用 78 项不再各建独立文章。详见 [科普内容规则](KNOWLEDGE_CONTENT_RULES.md)。

## 排布与交互

- 使用 `SearchField` 组成单个焦点表面；`FormGrid` 按容器宽度决定列数，`Field` 表达全宽及复合参数；相关布尔值用 `CheckGroup`；输入／结果用 `SplitView`。保留参数顺序、原始值和整行 label 激活。
- PC 有效利用宽度，窄屏按内容自然堆叠，避免以手机单列设计覆盖桌面。控件不裁切；长文本可换行，表格及长结果内部滚动。手机点击目标至少 44px；不能仅靠 hover 提供操作。
- 使用有界自动高度 `Textarea`，程序写入用 `setTextareaValue`；空结果使用 `EmptyState` / `Result`，不保留大块装饰留白。不能为了排版截断原始字节或输出。
- 表单控件必须有可访问名称；图标按钮必须有 label；复合字段的每个控件分别命名。保留明显焦点、键盘顺序和语义，禁用标签在点击、键盘、程序选择及初始选择中均不可激活。
- 标签、弹窗、展开说明分别使用 `tabsController`、`dialogController`、`disclosureController`。页面不能另写焦点恢复、ARIA 或开关时序。组件移动须保留原节点、文件、输入和监听器。
- 常驻工作区只呈现控件、真实状态与结果。操作步骤、功能介绍和重复的本地运行说明集中在页头“使用说明”，来源与授权集中在页末。已有说明覆盖的静态段落直接删去；动态说明节点以 `data-tool-help` 交给共享帮助，晚载内容使用 `appendToolHelpContent`，保留 ID、ARIA 引用和动态更新。不能用 CSS 批量隐藏 `.help`／`.ref-note`，这些类也承载有效读数与错误。
- 科普文章是用户明确要求的阅读内容，具体机制与例子直接呈现，权威文献在文章末尾集中展示一次；阅读操作说明仍在共享使用说明。复用 SearchField、Card、Result 和 ReferenceList，目录与正文在所有屏幕宽度分别占满工作区；阅读时只展示文章，返回科普目录保留筛选条件并恢复焦点，重入同篇不重建正文。优先国内官方资料及标准镜像；原文语言如实标示。来源引用区别于软件依赖，第三方文本、数据、素材若实际复制仍按其许可证保留署名。

## 动效与生命周期

- UI 动画优先使用已接入的 Animate UI 原语，由 `ui/animate-ui.js` 适配真实节点、`ui/motion.js` 和 `ui/components.css` 统一编排。页面只调用公共 `animatePresence` / `animateCollection`；不能用删除或明显弱化动画代替修复，也不能直接调用 WAAPI `animate`、写 animation / transition 内联样式，或增加页面关键帧与过渡。算法必要的 Canvas / WebGL 帧循环仍属于专用渲染，切页即停。
- 统一令牌：按压 100ms、焦点／反馈 160ms、进入 240ms、展开 260ms、弹窗／侧栏 300ms，曲线 `cubic-bezier(.22,1,.36,1)`，JS 读取同一组 CSS 令牌，支持 ms／s 并保留 0ms。触控位移更短，公共时长只能在组件样式中调整。忙碌转圈只用于真实执行状态。
- `ToolPanel` 根节点只淡入，不能变换包含 sticky / fixed 的页面根。动画必须可中断，从当前状态继续；集合使用稳定记录 ID，不用数组位置当身份。
- 连续输入、过滤、拖动、进度和图形每帧更新不反复播放进入。所有动效入口共用连续输入抑制；持续计算的只读文本使用 `setTextareaValue(node, value, {feedback:false})`，单次操作保留默认反馈。抑制动画不能阻止同步更新结果或公共自适应高度。
- hidden、inert、ARIA、焦点、取消和输入作废立即生效；动画不延迟逻辑、不复制用户内容、不推断 disabled 就是 busy。过期回调必须带修订号或任务 ID，不能覆盖新状态。
- 原生弹窗关闭及恢复焦点同步完成；退出只延迟视觉清理。保持退出期间纵向布局与可见视口尺寸；重开、销毁或完成时释放快照。抽屉保留原侧栏至退出完成，不能复制节点。
- 同时支持 CSS 与 JS 的实时 `prefers-reduced-motion`。隐藏、卸载、进入后台和偏好变化取消动画；没有能力支持动画时仍立即完成操作。不能用仅关闭动画的测试代替正常动效测试。
- 控制器和组件注册 `onDisconnect`，清理事件、ResizeObserver、RAF、Worker 或持有的动画。相关说明的按钮或面板任一端卸载都要清理；销毁可重复调用且不能再改变状态。同一批次内搬动节点不视为卸载。

## 数据与异步状态

输入、文件名和结果走 `text` / `value`，或在开发者模板中明确转义；模板不是通用 HTML 净化器。结果模型与展示分离，下载和续接使用真实字节。异步操作必须有输入变更失效、取消、限额、超时、失败恢复与过期结果防护。真正成功才标成功；清空、停止和失败不保留旧结果。默认本地处理，不暗中联网或上传文件。

Worker 的引擎、模块、字体、数据和 WASM 地址由页面模块的同源绝对基址决定，不能依赖临时 `blob:` 线程地址。共享加载适配须保留上游字节与显式联网操作语义；加载失败要明确传回任务并终止，不能只等待全局 error 事件或运行超时。引擎回归必须包含普通、Blob、子目录启动和失败后重试，并断言实际输出。

## 第三方接入与来源验收

- 新增或调整实际复用的代码、引擎、数据和素材时，同轮更新 `public/project-licenses.js`、`public/project-sources.js`、固定来源记录及随包许可／notice。关于页目录和实际任务页末的“所用项目与来源”必须一起完成，不能只登记后台清单或只在关于页展示。
- 混合成员来源在真实激活后的 `arg:tasksourceschange` 同步，事件仅传任务元数据；共享来源所有者保存组装后的面板基线，切回原生工具和重新挂载须恢复正确来源。异步结果由实际控制器租约提交，不能只写结果文本框而漏掉笔记／图稿等动作。二维码修复的 Worker／图片读取和 ZXing 回调在切成员、改源及卸载后均须拒绝过期回填。
- 每项来源写明真实项目、具体用途、项目链接、精确许可证及本地许可／notice 路径；数据、引擎核心与独立依赖条款分别保留。纯本站实现、浏览器 API、文献／规则引用和仅提供外链的服务不列为已集成项目，不制造空来源栏。
- 使用共享来源所有者按当前任务／方向组合实际依赖，并把来源放在工作区全部正文、动态结果和帮助之后。按需挂载、同面板换任务／方向和重新进入后，来源仍须可见、唯一且匹配当前功能；不能沿用已隐藏工具的页脚，也不能通过 CSS 隐藏缺漏或错误。
- 扩展任务在 `public/project-source-contracts.js` 明确声明来源，原创实现显式填写空数组；由 `project-sources.js` 统一拥有初始化、任务切换、即时许可和笔记子视图的来源显隐，不在启动代码里另写条件清单。来源回归对照实际任务清单，必须检测整份页脚缺失、错误项目、重复许可和不在页末的问题。
- 交付前逐项对照本轮新增／调整任务清单，核对实现依赖、关于登记、页末展示及许可／notice 文件。按变更范围保留首次进入、动态挂载、共享面板切换的来源行为回归；没有页末来源不能视作接入完成。版本公告与已实现内容同步，不将计划或外部网站功能计入本站能力。

## 根因修复流程

1. 先复现本轮失败操作，只记录与问题有关的输入、组件状态、视口或动态设置。定位问题所属的组件、控制器、层叠、资源、结果模型或引擎适配。
2. 修正拥有该职责的代码，按风险选择已有用例、针对性查看或必要的新行为回归。不能用页面补丁、固定延迟、隐藏错误或降低边界断言掩盖根因；小改动不强制新增测试。
3. 只验证改变的契约和少量代表性直接使用方，不遍历所有消费者。动态参数、键盘、视口、快速交互、卸载及动画结束状态仅在本轮涉及其行为时选择验证。

必要的新增持久回归登记到测试映射和完整 `verify:all`；低风险调整可采用针对性查看，不强制新增脚本。完整覆盖库保留组件、布局、动效、工具、PC／手机、键盘、字号、正常／减少动态、能力归属、发现、旧链接、输入保留、结果失效、功能族真实方向及科普内容等断言。日常仅执行本轮变化对应的用例和必要场景，不运行整张覆盖矩阵；套件粒度过粗时按测试规范采用针对性验证。计算逻辑改动需断言实际输出。当前 GitHub CI 按差异选择，手动 full 可运行全套；Gitee 尚无云端流水线。CI 状态以实际记录为准，分支保护由仓库管理员配置，不作为本地扩大或重复验证的理由。
