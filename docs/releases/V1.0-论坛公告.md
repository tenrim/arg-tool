# 迷雾工具箱 V1.0 更新公告

迷雾工具箱是一个给 ARG 玩家的中文工具工作台，用来查找资料、处理线索和记录解谜过程。绝大多数功能来自现有工具和开源项目的整合，具体来源与许可可以在关于页和相关工具页脚查看。

访问地址：[迷雾工具箱](https://www.tool.mistarg.cn/)

## 这次更新了什么

### 边处理线索，边记笔记

电脑端点击笔记本，可以直接在当前工具页面右侧打开。中间的分隔线支持拖动，想多留一些空间给工具或笔记都可以；需要集中整理时，也能转到独立的笔记页面。笔记、思维导图和线索白板仍属于同一个工作区。

### 笔记的删除和备份更完善

删除笔记后会先进入回收站，可以恢复；永久删除需要再次确认。多窗口编辑也增加了冲突保护，避免旧页面覆盖新内容。

文件菜单可以完整备份当前笔记，也可以备份包含回收站的全部笔记。备份保留附件、可编辑脑图与白板、原始来源数据；容量较大时会自动分批导出，每份都可以单独导入。普通笔记列表改用摘要索引，减少反复读取大附件，正文搜索继续保留。

笔记仍保存在当前浏览器中。清除网站数据、换设备或换浏览器前，请先导出完整备份。

### 查找与页面排布调整

搜索 Base32、Base64、Base85 等名称时，会优先找到相应工具，并选中对应的实际操作。收藏、最近使用和启动选项改为显示实际任务名称，工具数量与科普数量分开统计。

同时调整首页卡片、转换参数、输入与结果区域、点选方阵及查询页面，减少不必要的留白和重复控件，并检查手机布局、键盘操作和减少动态效果设置。

### 专业外站介绍与在线查询

补充按方向整理的专业外站介绍，每个网站仍保留具体介绍和链接。AperiSolve 放在图像与分析外站中，图片完整扫描需要前往其官网，本地图片分析和隐写提取功能继续保留。

在线资料查询修正了首次进入的提示，以及修改输入、切换任务和取消后的旧结果处理。查询只在主动提交后，通过本站服务器访问页面说明的资料来源；外站不可用时会明确提示，本地工具仍可使用。

### 部署与维护

网站、在线查询和邮件反馈由同一个启动入口管理，补齐了更新、恢复和笔记数据迁移说明。针对这轮修改验证了笔记备份恢复、搜索、查询生命周期、界面和来源登记。外部资料网站的可用性仍取决于上游，不能保证所有来源始终在线。
