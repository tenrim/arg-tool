# 迷雾工具箱 V1.5 更新公告

这次主要改善打开网站、查找工具和阅读资料时的体验：

- 首次打开增加带动画的加载页面，加载失败可以重试。
- 修复收藏和启动页恢复，重新打开时能回到具体工具及操作方向。
- 单位换算补齐中文单位名称，整理数值、结果和操作按钮的排布，改善手机显示。
- 普通计算器支持按键盘上的等号计算，科学计算器仍可输入等式。
- 长篇科普增加可折叠章节目录，合并重复参考资料，改善返回目录和资料定位。
- 鸟类目录默认展示物种，中文与常用信息优先，完整原始资料仍可查看和导出。
