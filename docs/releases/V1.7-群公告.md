# 迷雾工具箱 V1.7 更新

这次补了一轮日常能用到的计算器：海拔气压、水的沸点、露点与结露、冷热水混合、加热时间、耗电与电费、电池续航、溶液稀释，共 8 项。在“其他工具 → 数学计算”里，也可以直接搜索。
