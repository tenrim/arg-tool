# 迷雾工具箱 V2.1：工具界面简化与查询可靠性修复

2026 年 11 月 10 日

访问：[迷雾工具箱](https://www.tool.mistarg.cn/)。网页中的[关于](https://www.tool.mistarg.cn/#about)也能查看本次与历史版本记录。

这次主要处理两件事：让常用工具的页面更清楚，以及修复查询工具中会漏掉结果、改变查询含义或把加载失败当成未收录的问题。

## 高级参数和参数预设按需开启

高级参数、参数预设的入口默认关闭。需要时，可以到“设置 → 显示与编辑”分别开启，立即生效，并保存在当前浏览器。

开启后，仍可以按需展开具体内容。关闭显示不会清空已经填写的参数，也不会删除保存的预设；重新打开后可以继续使用。应用预设只填写参数，不会自动执行工具。密钥、初始向量等执行所需字段和常用参数继续直接显示。

这项调整同时接入共用表单和已标明进阶区域的工具，包括 CyberChef 扩展参数、条码生成设置、综合计算器内核选项、图片与声音互转的高级模式等。

## 输入与结果区域重新对齐

统一转换页面中输入框、空结果和实际输出的起始位置及基础高度。输入说明和示例放在整组编辑区前，参数预设使用独立区域，减少按钮、提示或折叠区把左右编辑框挤得错位的情况。

Magic、通用文字处理及文字隐写等共享页面一并调整。输入与结果继续使用原来的内容，切换显示选项不会替换输入或自动运行。完整结果、必要标签和错误提示继续保留。

手机根据可用宽度重新排布，长说明和操作按钮可以换行；较大的界面文字和编辑区字号会相应调整编辑区高度。保留编年史配色、字体和扫描线，并修正按钮组的悬停高亮归属、位置与遮盖，兼顾键盘焦点和减少动态效果设置。

## 资料查询修复

| 功能 | 本次调整 |
| --- | --- |
| 国家地区 | 国际电话区号支持 `+86` 等带加号的常见写法 |
| 机场 | 补齐原始资料已有的水上机场、气球场筛选，覆盖全部七种设施类型 |
| Unicode | 粘贴码位列表时允许周边空白；单独空格仍查询 U+0020；名称反查补回汉字、韩文等范围字符；修正西夏文字的标准名称 |
| 历史货币 | 不再将现代国家条件错误套用到历史货币，明确按原资料中的使用实体查询；保留国家和地图上下文，切回现行模式恢复筛选 |
| 英文正则查词 | 保留表达式的大小写与转义，以及自定义词表的原始大小写，避免条件被改成相反含义 |
| 拼音反查 | 不带声调时查全部声调；数字、调号继续精确匹配，`0` 表示轻声 |
| 成语与歇后语 | 修复问号在首位时漏查，每个问号对应一个字位；移除结果的静默截断，保留全部匹配 |
| COD 晶体资料 | 精确编号详情不再被普通检索的默认重复记录过滤规则排除；保留原站重复、错误和理论记录标记，普通搜索的默认语义不变 |

## 汉字释义与笔顺加载更可靠

汉字释义资料返回 404、503 或连接失败时，明确显示资料载入失败，不再误报“未收录”并提示成功。只有资料实际载入、且其中确实没有对应记录，才显示未收录。恢复连接后，同一个输入可以直接重试。

静态笔顺、逐笔动画和逐笔分图都会等待真实笔画就绪；多字逐笔分图要等全部字绘制完成，避免第一字出现后就宣布成功。修改输入、切换模式、停止或离开页面后，旧结果与状态及时清除；超时会明确提示，迟到的回调不会重新恢复旧结果。

这些修复继续使用原 cnchar 查询、字库和绘制能力，没有替换为缩减样本或占位图。

## 在线查询范围调整

移除当前不可用的 SIMBAD、VizieR 在线查询，并同步清理导航、搜索、关联入口、科普和后端提供方。本地深空天体目录、星座资料、天文计算及其他在线查询继续保留。

第三方服务的可用性仍取决于对应来源。本轮 DNS 外部解析实测超时，COD 也有间歇性连接失败；COD 精确编号修复有官方原响应和回归依据，但不代表所有联网请求已验证正常。页面会区分查询失败与真正没有记录。

本次没有新增云笔记同步。笔记和图稿继续保存在当前浏览器，重要内容建议定期导出备份。
