# 迷雾工具箱 V1.7：新增八项日常计算器，调整笔记入口

本次更新日期为 2026 年 10 月 28 日。

网站入口：[迷雾工具箱](https://www.tool.mistarg.cn/)

## 新增日常计算器

八项计算器都放在“其他工具 → 数学计算”中，也可以直接搜索名称进入。

| 功能 | 可以计算什么 |
| --- | --- |
| [海拔气压](https://www.tool.mistarg.cn/#altitude-pressure) | 由海拔估算标准气压，或由当地绝对气压反求气压高度。 |
| [水的沸点](https://www.tool.mistarg.cn/#water-boiling) | 根据当地绝对气压计算纯水饱和温度，也可先按海拔估算气压。 |
| [露点与结露](https://www.tool.mistarg.cn/#dew-point) | 根据空气温度、相对湿度计算露点，可填写表面温度查看液态水凝结的温度条件。 |
| [冷热水混合](https://www.tool.mistarg.cn/#water-mixing) | 已知两份水的质量与温度，计算混合温度；或按总质量和目标温度反求配水质量。 |
| [加热时间](https://www.tool.mistarg.cn/#heating-time) | 根据水的质量、初温、目标温度、输入功率和效率，估算加热时间与输入电量。 |
| [耗电与电费](https://www.tool.mistarg.cn/#electricity-cost) | 根据平均功率、每天使用时长、天数和自填电价，估算电量与电能费用。 |
| [电池续航](https://www.tool.mistarg.cn/#battery-runtime) | 支持 Wh、Ah、mAh，结合标称电压、可用容量比例、输出转换效率和负载功率估算续航。 |
| [溶液稀释](https://www.tool.mistarg.cn/#solution-dilution) | 按摩尔浓度反求取用原液体积、最终溶液体积或最终浓度。 |

## 公式和依据直接放在工具下方

每项工具都列出实际采用的公式、参数单位、模型假设、适用范围和原始参考链接，并补上对应的科普文章与完整算例。公式依据包括 IAPWS 的水饱和性质资料、NOAA/NWS 气象公式、OpenStax 教材，以及 EIA 等机构的电能说明。

页面会区分标准大气估算与实际气压、露点与霜点，也会写清恒定比热、加热效率、电池可用容量等假设。加热和电池页面默认的 100% 效率表示理想条件，实际使用时应按设备情况修改；溶液稀释按最终溶液体积定容，不把体积差当作精确溶剂用量。

这些计算均在浏览器内完成。结果支持复制、下载及加入笔记，保留本次输入条件、计算公式和参考来源；修改条件、切换求解方式或离开页面后，旧结果会立即失效。

## 笔记本入口与手机显示

笔记本改为右下角常驻的醒目按钮。桌面端仍打开原有笔记侧栏，手机端打开笔记本页面；字符输入键盘与它共用悬浮操作区，避免入口重叠。

修复手机深色模式下“新建笔记”文字与背景混在一起的问题，默认文字恢复浅色，悬停和键盘焦点状态也保留清楚的对比。

笔记仍保存在当前浏览器，建议定期导出完整备份。
