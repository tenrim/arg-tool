# 迷雾工具箱 V2.3 更新公告

## 图片隐写综合分析

打开「图片隐写综合分析」，选择一张图片即可预览原图。点击「上传并分析图片」后，工具箱依据实际文件格式选择适用的检查，逐项呈现元数据、可读字符串、文件签名、通道与位平面、颜色重映射和隐写候选。

常规检查适合快速浏览。深入检查会按图片格式增加尾随数据、文件雕刻、图像增强和 LSB 候选扫描等项目。每项结果直接显示在对应卡片内，可以查看文本、预览图和可下载文件。点击「进入具体功能」会带上当前图片及对应参数，例如从尾随数据卡片进入 StegoVeritas。已返回的结果可打包下载。

图片分析单个文件最多 20 MB。选图时预览在浏览器内生成，提交后才上传到迷雾工具箱的隔离处理服务。候选结果需要结合原图和题目核对。

## StegoVeritas 单项工具

新增图像增强、调色板索引、RGBA 位交织提取、LSB 候选扫描、图片尾随数据提取和支持透明通道的数据嵌入。已经有单项工作台的拆帧、元数据、文件雕刻与位平面功能，可从 StegoVeritas 页面进入原有工具。

## 图片输入与结果显示

- 图片分析、双图比较、图片分片、可接收图片的 CyberChef 文件输入等入口补上原图预览。换图、清空及跨工具交接时，预览随当前文件更新。
- 修复 PNG／BMP 隐写检测结果的换行，扫描组合按行展示，长文本可在项目卡片内换行阅读。
