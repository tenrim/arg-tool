# 迷雾工具箱 V1.5：启动、工具恢复与阅读体验改进

访问地址：[迷雾工具箱](https://www.tool.mistarg.cn/)

这轮集中修复打开网站、恢复工具和阅读资料时遇到的问题，并继续整理单位换算的界面。

## 启动与工具恢复

首次打开网站时增加带动画的加载页面，显示当前加载状态；加载失败时提供重试入口，保留原本要进入的工具链接。这项改动让等待和失败有明确反馈，不代表首次加载耗时已经完全消除。

收藏和启动页现在按实际工具恢复，保留专题中的具体功能与操作方向，避免重新打开后落到共用页面的默认工具。设置页的启动工具选项同步去重，旧版偏好备份仍可导入。

## 单位换算与计算器

- 数值与换算结果相邻展示，随屏幕宽度调整排布。
- 补齐 452 项随包单位的中文名称，整理单位符号；内核使用的详细记号放入可展开区域。
- 复制、下载、加入笔记和加入图稿的按钮统一排列，手机上自动换行，与交换单位、详细记号保留清晰间距。
- 继续随输入和单位选择实时换算，输入清空或修改时及时清除旧结果及其记录状态。
- 普通计算器支持按键盘上的 `=` 直接计算。科学计算器保留等式输入，Enter 和页面计算键照常使用。

单位换算仍使用原有本地内核，货币仍为随包固定汇率，没有改成实时汇率服务。

## 科普与资料阅读

长篇科普增加可折叠的章节目录，方便跳转；合并专题的重复参考资料，同时保留各节对应的引用。返回科普目录时恢复到原条目，信息技术资料选中记录和返回列表时也会将目标带入视野。

鸟类目录默认按物种查看，优先展示中文名称和常用信息，分类细节可展开。完整分类记录、原始字段、工作簿导出和来源许可继续保留。

常规工具仍在浏览器内处理输入和文件，在线查询与问题反馈只在主动提交时发送必要内容。笔记保存在当前浏览器中，建议定期导出完整备份。遇到问题或有改进建议，欢迎反馈，也可以在群里 @我。
