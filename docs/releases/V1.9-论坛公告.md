# 迷雾工具箱 V1.9：文件比较、批量处理与笔记快捷侧栏

2026-11-02 更新。访问：[迷雾工具箱](https://www.tool.mistarg.cn/)，网页中的[关于](https://www.tool.mistarg.cn/#about)也可以查看完整版本记录。

## 文件版本比较

新增[文件版本比较](https://www.tool.mistarg.cn/#file-versions?task=native%3Afile-versions)，可以选择两组文件、文件夹或 ZIP，按相对路径查看新增、删除、修改和不变的文件。两边内容完全相同且只有唯一对应时，会提示“疑似改名”。

比较使用完整文件字节，支持文本和十六进制预览，并可导出完整比较报告。预览较长时会标明截短；字节差异统计不等于逐行文字编辑差异。ZIP 保留内部路径，不支持加密、分卷或 ZIP64。

## 多文件批量处理

新增[多文件批量处理](https://www.tool.mistarg.cn/#file-batch?task=native%3Afile-batch)，目前支持：

| 操作 | 用途 |
| --- | --- |
| SHA-256 | 批量计算文件摘要 |
| Base64 编码／解码 | 文件与 Base64 内容互转 |
| 文本换行统一 | 将 UTF-8 文本换行统一为 LF |
| PNG／JPEG／WebP 转换 | 转换静态图片格式，调整最长边及适用格式的质量 |

处理时逐项显示状态，可停止、单独重试失败项、逐项下载，或把成功结果打包为 ZIP。每批最多 500 个文件，单文件最多 32 MiB、输入合计 64 MiB、输出合计 32 MiB。图片转换不保留动画和原始元数据，JPEG 使用白色背景。

文件在浏览器本地处理，不上传、不覆盖源文件。

## 工具参数预设与加载反馈

在支持的参数区可以保存多份常用设置，并进行应用、重命名和删除。预设按工具及操作区分，最多 100 份、合计 128 KB，只保存获准的选择项、数值和开关，不保存正文、文件、密码或密钥。应用预设后仍由玩家点击执行。

CyberChef、综合计算器、单位换算及延迟载入页面增加实际加载阶段提示，区分引擎准备和计算过程。新增文件工具可以停止和重试，进度提示不会用虚构百分比代替真实状态。

## 点开就能写的笔记

保留右下角“笔记本”按钮，点开后直接显示可编辑、自动保存的笔记。桌面为可调宽侧栏，手机使用窄屏面板；没有笔记时自动创建一条。笔记列表和格式工具可以按需展开，也可以进入完整页面整理笔记、脑图和白板。

侧栏和完整页面使用同一套笔记与编辑器，打开时保留当前工具的输入。修复快速新建笔记时输入可能抢在切换前发生的问题，保留关闭后的焦点和浮动键盘入口。笔记继续保存在当前浏览器，需要跨设备使用时请导出备份。
