# 迷雾工具箱 V1.1：界面、交互和搜索体验更新

访问地址：[迷雾工具箱](https://www.tool.mistarg.cn/)

这轮主要整理了实际使用时容易遇到的界面和交互问题，让找工具、切换参数、查看结果和记录线索更顺手。

## 工作台界面调整

统一了顶栏、侧栏、页脚、任务按钮和参数表单的排布，保留迷雾系列的深色、琥珀与青色风格，调整了电脑和手机上的间距、对齐与显示方式。

## 补齐交互和动画

这次实际接入了 Animate UI 2.0 和 Motion。普通单选下拉、弹窗、手机抽屉、折叠、标签切换和按钮反馈采用统一的组件与动效，侧栏、页头和工具栏加入连续滑动的悬停高亮。

同时修复了高亮遮住文字、展开收起时跳动、快速开关后的状态残留，以及动态下拉选项和弹窗内键盘操作等问题。连续输入时不会反复播放入场动画；系统或本站的减少动态效果设置会实时生效。

浏览器文件选择器、系统权限提示，以及笔记编辑器、脑图和白板内部界面，仍保留各自的实现。

## 搜索增加文字高亮

搜索结果现在会直接标出匹配的文字。如果命中的是功能别名、具体操作或说明，会在标题下显示对应片段，方便看出为什么搜到了这个工具。

例如搜索 ASCII，可以在“字符编码与码点”的结果下看到匹配名称；搜索 From Base64，会优先显示对应的完整操作。英文拼写略有偏差时，也会显示模糊匹配的位置。

顶部搜索、首页工具导航、侧栏筛选和完整工具目录都已使用这一能力。原来的中文输入法、方向键、Enter、Escape 和 Tab 操作继续保留，并修复了长结果列表的焦点问题。

## 笔记侧栏体验改进

优化了右侧笔记本的打开、关闭、拖动调宽和转到独立页面的过程。操作时保留当前工具的输入、选中文件和原编辑器内容，方便一边处理线索一边记录。

本轮补齐了实际使用组件的来源与许可证说明，并完成相关搜索、布局、动效、任务切换和笔记回归检查。
