# 迷雾工具箱 V1.8：笔记本完善、出行财务计算与函数绘图

2026-11-01 更新。访问：[迷雾工具箱](https://www.tool.mistarg.cn/)，网页中的[关于](https://www.tool.mistarg.cn/#about)也能查看本次和历史更新。

## 笔记整理与附件管理

笔记增加项目／文件夹、标签、置顶、排序、复制和批量整理，可以插入其他笔记的引用，也能查看哪些笔记引用了当前笔记。搜索除了标题和正文，还能找到附件名、UTF-8 文本附件、脑图节点与备注、白板文字。

附件可以重命名、替换、下载或删除；整张脑图和白板支持重命名、复制、删除及跨笔记移动。增加历史版本预览、恢复和下载，完整笔记备份会包含历史。

历史从新版启用后开始记录，不能找回过去没有保存的版本。自动编辑约五分钟形成检查点，管理操作另外保留检查点；每篇最多 20 份，历史正文与附件合计最多 64 MB，达到上限后轮换最旧记录。含历史备份超过大小限制时，可以备份当前状态，并单独下载历史版本。

## 脑图和线索白板

笔记标题和列表可以生成脑图层级。关联图稿可以打开来源笔记、主动从笔记更新，也可以预览后确认写回；更新时保留匹配标题节点的标识和样式。

修复白板重开后字体、填充等样式被覆盖的问题，保存白板素材库和图稿视口。同一页面会话中切换图稿后仍可继续撤销；刷新后使用历史版本恢复，原生撤销栈不会跨刷新保存。

导出支持透明 PNG、SVG、1024／2048／4096 尺寸选项，以及 Excalidraw、Mind Elixir 原生文件；白板可仅导出选中对象。脑图增加 OPML、Markdown 和新版 JSON 型 XMind 大纲交换。交换主要保留文字、层级和备注，旧 XML 型 XMind 不支持，XMind 专属样式、布局等不保证无损；原始导入文件保留，完整图稿请使用本站格式备份。

## 新增出行与财务计算

| 工具 | 可以计算的内容 |
| --- | --- |
| 行程与配速 | 路程、移动时长、平均速度和每公里配速互算，加入停留时间 |
| 行程能耗与费用 | 油耗或电耗、能源费用、额外费用、每人及每公里费用 |
| 反应与制动距离 | 反应距离、恒减速度下的制动距离和时间 |
| 利息与本息增长 | 单利、完整周期复利、本息及有效年利率 |
| 贷款还款计算 | 固定年利率下的等额本息，完整逐期本金、利息和余额 |

每个工具下方都有实际采用的公式、参数单位、适用条件、算例与参考来源，依据包括 OpenStax 公开教材和美国能源部 AFDC 计算方法。利率、油价、电价等由用户填写，不获取实时银行报价或能源价格；制动计算是简化模型，不代表实车安全距离。计算在浏览器内完成，复制、下载或加入笔记时保留条件、公式和来源。

## Desmos 函数绘图

函数绘图改为在工具页内打开 Desmos 官方中文计算器，首次进入才联网。切换工具保留当前页面；刷新前需要使用 Desmos 自身保存或分享。内部界面、表达式、账号和保存由 Desmos 处理，本站不会读取跨域表达式或自动写入笔记。

## 搜索与界面

普通搜索默认不索引科普。在“设置 → 使用习惯 → 搜索中显示科普”开启后，顶部、侧栏和工具目录搜索会纳入科普，即时生效并保存在当前浏览器。科普目录和“相关科普”入口继续保留。

统一笔记本按钮和编辑器工具栏的悬停、键盘焦点反馈，修正页头样式覆盖。综合计算器使用自带键盘时减少手机系统软键盘遮挡，保留硬件键盘输入。

笔记、图稿、历史和素材库继续保存在当前浏览器，不新增云同步或多人协作。建议定期导出备份。
