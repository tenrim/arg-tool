# 迷雾工具箱 V1.2：计算、动图与解谜工作区完善

访问地址：[迷雾工具箱](https://www.tool.mistarg.cn/)

这轮主要把已有项目中适合解谜的能力整理成能直接操作的工具：常用功能有明确的按钮和表单，复杂但有用的操作放进进阶区，解谜时用不上的专业入口则撤下。

## 综合计算与单位换算

新增普通和科学计算器，可以用按键或键盘输入算式，支持括号、百分数、平方、开方、三角函数、对数、幂和阶乘，也可以使用内存与上次结果继续计算。

单位换算按类别选择，支持查找原单位、目标单位和交换两侧单位，统一承接原来的同类换算入口。长度、面积、体积、质量、时间、温度、速度和数据容量等由同一个本地 Qalculate 内核计算；货币使用随包固定汇率，并非实时行情。

页面名称统一为“综合计算与单位换算”，移除了完整定义目录和自定义函数、单位、本地数据等复杂入口。计算精度、历史、结果保存和已有数学内核仍保留，暂不增加带单位数量的公式计算表单。

## 动图逐帧分析

新增 GIF／APNG 查看与分析，支持播放、逐帧前后移动、查看原始局部帧，以及比较相邻帧的差异，方便检查动图里一闪而过的内容。

可以导出当前帧、全部帧 ZIP、精灵图和完整参数，也可以按网格切片。完整导出保留对应原始数据；超过处理限额会明确报错，不会悄悄截掉后面的帧。

## 多形状魔方观察

魔方工作区扩充为固定库中的 21 种形状。可以输入公式、前后步进、手动追加转动并保存观察记录，用来复现题目给出的状态或转动过程。

不同形状使用实际支持的二维或三维视图，并非所有形状都有三维显示。自动求解和竞速打乱入口已撤下。

## 汉字、乐理、序列与科学资料

- **汉字**：完善字形、逐笔、笔顺、释义和组词查询，完整笔画与字典记录可以展开查看。
- **乐理**：增加直接可用的音程与移调表单，保留音名、频率、和弦和音阶。
- **生物序列**：增加线性／环形查看、位置、搜索、错配和正反六阅读框翻译；保留文件中全部解析序列、注释与原文件。
- **元素与化学**：118 个元素的原始字段完整保留，常用字段在前、全部字段可展开；保留符号拆分、分子式计数、结构图和常用标识。
- **天文与历法**：增加当地日食查询和星座归属；佛历、道历作为可选文化参考。

姓名随机生成、专业反应与化学库管理、泛用原生方法／JSON 工作表等不适合当前解谜用途的入口已从玩家界面撤下。

## 图片、二维码、视频与处理链

图片增加原始调色板和 RGBA 导出，文件／图片嵌入放进进阶区。二维码常用修复继续直接操作，码字编辑和完整分块诊断归入进阶内容。

视频提供常见输出格式选择，原生命令仍保留在进阶区，由本地 FFmpeg 执行，完整结果和日志可以保存。支持范围以随包内核实际具备的能力为准。

完整 CyberChef 处理链增加多输入标签、断点、单步、输入输出选区对应高亮，以及 Magic 候选采用。候选是分析建议，采用后仍需实际运行、核对结果。

## 界面与记录

统一了任务标题的字体、字重及手机字号，修复动态加载页面时标题回退到另一套字体的问题。相关使用说明、科普、笔记／图稿保存和来源许可也一并整理。

常规工具继续在浏览器内处理输入和所选文件；在线资料查询与问题反馈仅在主动提交时发送必要内容，页面会说明实际去向。

笔记保存在当前浏览器中，建议定期导出完整备份。遇到问题或有改进建议，欢迎反馈，也可以在群里 @我。
