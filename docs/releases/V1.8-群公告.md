# 迷雾工具箱 V1.8 更新

这次主要把笔记本、脑图和白板补了一轮：可以按项目和标签整理笔记，置顶、批量整理、互相引用，也能管理附件和移动图稿。加上了历史版本恢复，搜索可以找到附件和图稿里的文字。白板重开后样式变化、按钮悬停不统一的问题也修了。

图稿可以导出透明 PNG、SVG 和原生文件，脑图增加 OPML、Markdown、新版 XMind 大纲交换。历史从新版启用后开始记录；XMind 专属样式不保证无损，完整图稿仍建议用本站格式备份。

新增 5 项出行和财务计算：行程与配速、行程能耗与费用、反应与制动距离、利息与本息增长、贷款还款。每项下面都有公式和参考来源。函数绘图改为页内打开 Desmos 官方中文计算器，需要联网。
