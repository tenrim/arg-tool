# 迷雾工具箱 V2.3.5 更新日志

2026 年 11 月 22 日

这次小更新主要缩短了「文本线索分析」的等待时间。点击「分析文本」后，找到的候选会陆续显示。看到有用的内容就可以先查看或复制，其他分支会继续分析。

默认三层分析中，仿射密码试解会复用已经算过的结果。词典替换和英文查词先后用到同一份完整英文词库时，首次只需下载约 0.99 MB，第二次会校验并复用已有内容。词库保留全部 214,093 条记录。

正式站用同一段 Base64 文本，在三个全新的桌面 Chrome 会话中测试。默认三层从首次点击到出现正确候选的中位数为 **0.42 秒**，完整跑完的中位数从 **35.10 秒降到 12.59 秒**。三次都得到 1,150 个候选。
