# 迷雾工具箱 V1.3：实用计算与符号录入体验优化

访问地址：[迷雾工具箱](https://www.tool.mistarg.cn/)

这轮围绕计算、查找和录入做了调整，补上常用的日期、地理与几何计算，也把一些原本需要多点几步的操作简化了。

## 计算器与实时单位换算

综合计算器重新整理为显示屏与集中按键的布局，普通和科学模式继续共用计算内核。历史、设置和完整结果放入侧边面板，修复了按键高亮在不同行之间滑动的问题。

单位换算从计算器中独立出来，在“其他工具”下按学科分类。修改数值、切换原单位或目标单位后，结果会实时更新，不需要再点击计算；也可以交换两侧单位。原有单位继续由同一本地 Qalculate 内核运算，货币使用随包固定汇率，并非实时行情。

## 日期与跨时区规划

- **日期加减**：按年、月、周、天推算日期，并处理月末和闰年。
- **日期差**：查看相隔天数、周数、日历年月日间隔，以及周一至周五的天数；可选择是否包含结束当天。
- **年龄计算**：查看周岁、已过天数和下次生日，闰日生日可选择约定。
- **倒计时**：按所选时区设置目标时间，查看剩余或已经过去的时长。
- **ISO 周与年内日序**：查询日期属于哪一周、周所属年份和年内第几天，也可由 ISO 周反查日期。
- **跨时区会议规划**：比较多个地点的起止时间，按各地可用时段和周末条件寻找共同空档。

日期差中的周一至周五计数不包含各地节假日和调休；跨时区规划使用随包时区规则，未来政策变化可能影响结果。

## 地理、几何与摩尔质量

地理距离与方位角现在有独立入口，可输入两地坐标，查看大圆距离及适用的起始、终到和反向方位。它使用球面模型，不是道路里程。

几何工具提供 19 种常见图形，可按相应尺寸计算面积、周长、体积或表面积，并显示公式和示意。新增 BMI 数值计算，支持公制与英制输入，不提供健康诊断或人群分级。

摩尔质量与分子式工具增加总原子数、各元素的质量贡献与占比，支持方括号、Unicode 下标及结晶水写法。结果使用随包元素表的原子量近似。

## 盲文与旗语直接录入

盲文和旗语现在默认展示可点选的图形按键，点击字母就会录入结果，可连续点击输入重复字母，也支持键盘操作。按键模式不再额外显示追加按钮。

盲文按键只列出 A–Z 字母及供对照的数字标记，去掉没有对应字符的图形。原来的逐点输入与旗语方向输入仍保留，可通过录入方式切换；手动组合完成后确认录入，切换时保留当前选择，不会自动重复写入。

## 布局与资料展示

改善窄屏、参数标签和复合选项的排布，减少控件挤压与换行错位。鸟类等资料页优先显示常用信息，补充资料和完整原始字段可展开，原始数据、导出与来源许可继续保留。

最近使用现在按实际工具工作区归并，同一盲文专题的不同功能不会再各占一条记录；再次打开时仍会回到实际使用的功能。

移除了“输入或设置已改变，请重新计算”等多余提示。编辑输入或设置时会清除旧结果，实际运行进度、错误、限额及主动联网去向仍会明确显示。

常规工具继续在浏览器内处理输入和文件，在线查询与问题反馈仅在主动提交时发送必要内容。笔记保存在当前浏览器中，建议定期导出完整备份。遇到问题或有改进建议，欢迎反馈，也可以在群里 @我。
