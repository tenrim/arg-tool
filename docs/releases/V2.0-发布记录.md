## 新服务与 20 MB 限制

正式文件分析镜像：`sha256:030b69297c9f1043fd0127131ba2f8082b90e02827ed0bcfd77c53a344e64c20`。它在此前实测的 `bcd318ee6024…` 镜像上只更新本站执行器的 20 MB 校验，没有重新安装或升级第三方分析器。

代码运行镜像：`sha256:7ce4b43845397f947a970938eb38bc6a10f55ebcf6715e98fd3ebe126a66689b`。继续使用此前逐种实测的 17 种服务器语言环境。

所有上传／交给服务器处理的文件上限为 20 × 1024 × 1024 字节；已有更低限制保持。当前文件上传分析入口的浏览器、HTTP 校验和隔离执行器均已调整。反馈请求原有 6 MB 总上限、代码／标准输入原有各 256 KB 上限均不放宽。纯浏览器本地工具保留各自限制。文件分析请求的代理上限为 28 MB，用于容纳 Base64 和 JSON 包装，不表示原文件可达到 28 MB。恢复结果仍保留原先完整结果总量 64 MB 的输出边界。

网关只调度原有服务：两个请求路径、固定镜像、原并发限制与取消机制。任务容器禁网、非 root、只读根文件系统；仅可信网关使用 Docker socket，玩家程序不能取得它。代理不缓存请求和响应到临时文件。

### 自动化环境限制

本机自动化 Chromium 和 Chrome 在 HTTPS 及 localhost 页面上保存下载均返回 `canceled`，最小的纯文本／空白 ZIP 对照也一样；进一步在完全未加载工具箱代码的空白页测试纯文本下载，仍返回相同取消结果。分析结果的 Blob 仍存在，没有被撤销；实际生成的 1,318 字节 ZIP 及其中恢复内容已独立核对。本轮未据此修改网站下载实现或关闭浏览器安全功能，也未把字节核对写成系统保存下载通过。需要在正常用户浏览器中补验保存文件这一步。此前的实体手机限制仍适用，窄屏为浏览器视口验证。
