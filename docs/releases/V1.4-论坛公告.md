# 迷雾工具箱 V1.4：科普内容扩充与工作台体验完善

访问地址：[迷雾工具箱](https://www.tool.mistarg.cn/)

这轮主要补充科普内容、调整阅读与操作界面，并修复坐标、音频、文件处理和工具切换中的一些问题。

## 科普内容与全页阅读

扩充全部 256 篇科普文章，补写知识介绍、规则原理、处理步骤、实例、参数及适用边界。编解码专题继续保留各成员的具体机制与例子，不用一段总述代替不同算法的说明。

正文采用客观介绍和中性标题，参考资料集中在文章末尾。阅读文章时不再与目录各占半边；目录和正文分别全页展示，宽屏目录按可用空间排列为多列，手机保持单列。搜索、返回目录和前往实际工具的入口继续保留。

这次也调整了章节层级、段落与示例的宽度，减少标题不明显、正文和例子宽度不一致等问题。

## 表单、换算与设置

- 调整工具页头与辅助操作的轻重，改善参数、结果和空状态的排布。
- 日期计算将年／月、周／天整理为明确的输入组，随宽度换行。
- 单位换算移除多余的名称／符号搜索框，保留分类、单位选择与实时换算，突出结果显示。
- 在线查询的模式和条件使用响应式分栏，改善手机上挤压、错位的问题。
- 设置页分开“备份与恢复”和“重置与清理”，统一文件选择入口，并突出需要谨慎使用的清理操作。
- 减轻静态扫描线纹理，统一部分字号、间距与控件样式。

## 实际使用问题修复

- 修复南纬度分写法和负零度分坐标可能被读成正数的问题。
- 修复倒放后导出的音频片段与试听时间轴不一致，以及 SSTV 使用的音频方向与当前视图不同的问题。
- 修复音频分析中途切换工具后，返回时按钮可能仍被禁用的问题。
- 修改文件十六进制偏移时，清除旧输出及其记录状态，避免继续使用过期结果。
- 修复快速切换工具方向可能漏掉后一次选择，以及最近使用未保留当前方向的问题。
- 修复动态下拉选项过滤、重排与键盘检索时的选择同步问题。
- 修复中文输入法确认被误作计算提交、时区数据载入时原选中项可能丢失，以及笔记编辑器全屏被页头遮挡等问题。

## 页面进入动画与代码整理

页面进入继续使用项目内的 Animate UI，统一跨面板和共用面板的切换效果。修正过渡参数覆盖、主区域分批启动、控件重复初始化与旧动画排队渲染回写的问题，快速切换时从当前状态继续。错误提示观察器改为处理发生变化的状态，不再因普通控件变化反复扫描所有工具页面。

常规切换的流畅度已有改善，但首次加载仍可能出现短暂卡顿，本次不将其描述为完全消除。

同时拆分音频、文件及实用计算的界面与状态模块，使路由、计算模型、输入和结果各自承担明确职责。原始文件、本机处理方式和来源许可继续保留。

常规工具仍在浏览器内处理输入和文件，在线查询与问题反馈只在主动提交时发送必要内容。笔记保存在当前浏览器中，建议定期导出完整备份。遇到问题或有改进建议，欢迎反馈，也可以在群里 @我。
