# 鸟类、古典音乐与天文目录中文资料补充

本轮只补充已有资料的中文检索和展示，不替换原始记录，不把译名数量当作数据库规模，也不在玩家查询时联网。

## 鸟类

- 原始 AviList v2025b Extended 的 33,684 条记录、26 列和六张工作表全部保留，包括 11,131 个种、19,879 个亚种及目／科／属。
- 中文名来自 [IOC World Bird List 15.2 官方多语言工作簿](https://www.worldbirdnames.org/Multiling%20IOC%2015.2.xlsx)，完整固定原件包括 11,227 个种的多语言字段和 `Sources` 工作表。
- 只把完整学名完全相同、等级为种、且原表至少有一份中文名称的记录相连。本次获得 **11,075 个种**的中文名称；其余 56 个种及目、科、属、亚种仍用原名。不会猜测异名、属名变化、分类拆分或合并，也不把种名冒充亚种的专有中文名。
- IOC 原表简体与繁体列分别展示，搜索同时覆盖两列，并使用固定 OpenCC 搜索归一化。原始名称、学名、分布文字和记录编号不改写。
- 分布说明仍为英文。Unicode CLDR 48.2.0 的英文地名与中文标签仅提供完整词边界的辅助关键词；较长地名优先、不重叠匹配、同英文名指向多地域时不猜测，避免把 `Nigeria` 当作 `Niger`。这不等于翻译分布、判断国界或补足原文没有写出的地点。
- IOC [官方页面](https://www.worldbirdnames.org/new/ioc-lists/master-list-2/)原始 HTML 页脚声明 **CC BY 3.0 Unported**；固定工作簿 `Sources` 第 6 行给出的引用年份为 2026。中文名作者、台北市野鸟学会繁体名来源以及完整许可随补充资料保留。原始 AviList 自身仍按 CC BY 4.0 署名。
- 附表、分类决定和文献说明尚无可直接批量对应导入的中文原文，页面明确保留原文，不逐行手写翻译。

## 古典音乐

- 原始 Open Opus 快照的 **220 位作曲家、24,975 部作品**及全部字段不变；原始快照仍可按原关系重建。
- 中文姓名与别名来自 [Wikidata](https://www.wikidata.org/)。维护脚本先要求官方搜索响应中的英文标签／别名规范化后完整相等，再核对唯一人物实体和原快照的出生年、逝世年（原表提供时）。不凭模糊姓名、搜索排序或手工翻译指定身份。
- 本次 **208 位作曲家**通过核对并有现成中文名称；其余 12 位存在源年份差异、无法确认唯一身份或没有已有中文名，保留原名，并保留未匹配报告。
- 所有成功 API 原响应、实际请求地址、读取时间完整压缩留档；中文记录保留 QID、实体修订号、原语言标签及别名。结构化资料使用 **CC0 1.0**，不混入维基百科正文或肖像。
- 已有时期、体裁的中文展示标签加入对应记录的检索。另从具有真实音乐形式／音乐体裁类型声明的 Wikidata 实体批量取得 **14 项**现成中文术语，仅匹配原作品标题中的完整英文词。例如原题中有 `Symphony` 时可用“交响曲”查找。
- 音乐形式只使用来源实体的正式中文标签辅助检索；不把“组曲”的宽泛别名“巴洛克组曲”索引为所有组曲的创作时期。原始标签、别名仍完整留在固定术语数据中。
- 音乐形式关键词不是完整作品标题翻译，也不冒称已经确定每部作品的分类。作品全名、描述、未匹配作曲家依然显示原文；没有按完整作品身份可直接核对的全量中文数据时，不自行写译名。无录音、乐谱和肖像资料。
- 完整中文别名匹配优先于更长姓名中的子串，因此“莫扎特”先显示 Wolfgang Amadeus Mozart，随后仍可保留另一位姓名本身包含 Mozart 的作曲家记录。

## 天文目录

- 星座检索加入原有官方图谱元数据的标题，巨蛇座的“蛇头／蛇尾”及 `Serpens Caput/Cauda` 均指向同一巨蛇座完整记录。
- 日月食目录支持 `2024年4月8日`、`2024 年 04 月 08 号`、全角数字及 `2024年` 等日期写法，仍按原目录的天文年份、儒略历／格里高利历校验。中文日期只作无损格式展示，NASA 原行、原日期字段、原始时间尺度和全部事件不变。

## 固定来源与维护

固定来源在 `upstream/atlas-chinese/`，`pins.json` 给出每份文件的字节数、摘要与来源。完整原版 IOC 工作簿和许可声明页面保留；Wikidata 全部成功请求原响应保留在 `wikidata-responses.json.gz`，派生中文姓名与术语分别保存。

首次明确采集缺失的 Wikidata 响应：

```powershell
node scripts/import-atlas-chinese.mjs --acquire --snapshot-date 2026-10-17
```

脚本串行请求并限制请求间隔，失败即停止，不用猜测结果填空。恢复同一份采集时复用已存原响应。IOC 原件与许可文件已固定；若恢复缺失原件，应从 `pins.json` 的官方地址取得并核对原摘要，不用新版本替换旧快照。

仅用固定响应重新投影并校验来源（不联网）：

```powershell
node scripts/import-atlas-chinese.mjs --offline --snapshot-date 2026-10-17
python scripts/build-atlas-life-culture.py
```

主构建不执行联网采集。生成器核对所有固定来源摘要，再把中文补充放在原数据旁；原始行数组、`raw`、本地 ID、作品所属作曲家和原始字段全部不动。普通网页查询只读取本站固定资源。每条可保存记录的展示字段同时携带补充来源、许可、版本／修订及日期，完整原始记录仍单独保留。
