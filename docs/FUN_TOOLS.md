## 实现所有者

`public/fun-tools/`：目录与专用工具控制器；文本、图像、声音和二维码传输分别拥有业务状态。共用组件只组成界面，不拥有算法状态。后台运算使用有修订号、可终止的 Worker。

`upstream/fun-tools/`：逐项目固定源码与 SOURCE.json，保留原字节。

`public/vendor/fun-tools/`：固定或可重复生成的运行资源，GPL 模块单独标记并提供对应源码和构建入口。

## 验证记录

本轮已接入上述十项能力，合并为八个工作区：图片混淆、视觉密码、文本隐写、兽音译者、佛又曰、图片与声音互转、化物为图、二维码传文件。StegCloak 与郭飞文本水印各自保留完整格式；SpectroTrace 与 Spectrum 各自保留完整参数与算法。

已通过的本轮验证：

- `node --test tests/fun-tools.test.mjs`：9 组模型／原版互通测试，包括裁剪逐像素与越界校验、全部 65536 个 UTF-16 码元、兽音自定义字典和首尾格式、StegCloak 加密/HMAC 四种组合、原版 AES 映射互通、Rust LCG 已知字节、矩形 Gilbert 映射、视觉分片覆盖率、空文件与尾零、二维码乱序重复／CRC／SHA／长文件名。
- `node scripts/browser-fun-tools.mjs`：8 个真实任务页面；实际表单、方向草稿、下载、结果失效、裁剪与参数重置、Spectrum PNG/WAV 往返、质量分析、相位精修后保留质量分析、二维码图片接收、入口二维码还原地址并打开真实接收页面、320 像素页面布局及正确来源页脚。
- `node scripts/browser-fun-tools-advanced.mjs`：38 组音频参数组合；五种 FFT 窗长与全部 Compact 位深、Exact、任意图片、高质量恢复、截取和重采样；WAV/MP3/FLAC/Vorbis/Opus/AMR/AAC 七种本地解码回退；真实 Worker 取消和重试；合成视频进入 getUserMedia 接收链，完成扫码、SHA-256 与轨道释放。
- `audit:ui`、架构审查、事件审查：公共组件入口、模块依赖、来源通知契约通过。供应商完整性由 `scripts/audit-fun-tools.mjs` 校验；主构建调用该离线校验。
- 本轮模型、能力目录、来源许可与科普章节相关的 34 项单元检查全部通过；主离线构建成功生成 `dist/`。

摄像头测试使用合成视频，不代表已经实测实体手机的镜头、对焦与光照条件。第三方格式原有的有损、无认证、容量和平台字符清理边界已在工具帮助与科普中写明。错误输入与容量超限给出失败，不输出占位结果或静默裁剪。
