# 资料内容与中文检索排查

后续本地中文适配见 [实现范围与维护说明](REFERENCE_CHINESE_ADAPTATION.md)。下文保留修正前的排查记录，不能用作修正后覆盖率。

核查日期：2026-10-17。核对当前注册的 **36 个资料查询入口**，并补查内置词库、图片元数据、MIDI 音轨资料与科普。古典音乐之外，鸟类、历史时区、机场、运输地点、颜色名称、Unicode 名称，以及首都、部分深空天体与地质名称，都存在中文名称或中文索引缺口。

本轮产物是排查清单，没有修改运行代码、固定数据或上游文件。

## 核查口径

- 读取实际运行数据、构建来源、展示字段及真实查询所有者；本地例子调用现行查询函数，不依据中文页面标题判断资料语言。
- 下表 `0` 是本轮指定输入的实际命中数，不表示所有中文输入均失败；数字、目录号、学名和标准代码按原样保留。
- “没有汉字”可证明缺少汉字形式名称；“含汉字”不能单独证明是准确中文译名，也不能把重复的中文通用说明算作具体实体的中文资料。
- 在线来源核对当前适配器及 **2026-10-17 已保存的公开示例响应**，本轮没有重新发起外站查询。没有把单条英文结果推广成整个上游数据库只有英文，也没有断言上游完全不支持中文。
- 科普原始文献、法律原文、代码关键字、作品编号、IANA ID、MIME、SMILES 等不因保留原文就算作翻译缺陷。

## 2. IT 资料中的部分中文化

这些页面确实有中文说明，但许多是重复的类型解释，具体实体仍只有原始名称。以下“专门中文说明”指构建时实际匹配到的教育注释，不等于完整翻译覆盖率。

| 子资料 | 专门中文说明条目／记录数 | 实际检索差异 |
| --- | --- | --- |
| 服务端口 | 34 / 14,536 | `多路复用` 0，`Multiplexer` 8；`文件传输` 10，`File Transfer` 33 |
| IP 协议号 | 6 / 152 | `互联网组管理` 0，`Internet Group Management` 2 |
| HTTP 字段 | 21 / 263 | `内容安全策略` 0，`Content-Security-Policy` 2；当前已有译名“网页资源策略”，属于常用译名关联不足，不能称该字段没有任何中文 |
| MIME | 18 / 2,522 | `超文本` 0，`html` 9；`图像` 6，`image` 119 |
| 字符集 | 11 / 258 | `拉丁` 0，`Latin` 24 |

HTTP 状态码应另看：67 条中 64 条已有专门中文说明，`未找到` 和 `Not Found`均能查到，不能把状态码与字段合并判为全英文。域名与公共后缀是规则和标准标识的解析／检索，IDN 中文规则本身可查；它不是国家中文名称数据库。

## 5. 已检查且不应误报的内容

- **天体位置与升落、传统历法、海事信号旗**：中文选择、结果及含义可用。历法实际返回“正月初一、甲辰、龙、春节”和中文节气；海事旗“有人落水”“需要援助”可检索。天文目录对象名称的缺口归深空目录，不是太阳系计算引擎问题。
- **元素、分子式与生物序列**：118 个元素全部有中文名并参与检索；27 个氨基酸／模糊／终止代码项有中文。分子式、SMILES、DNA/RNA 等属于明确的公式／结构／序列输入，标准写法不改成中文。
- **汉字、中文词语与英文查词**：中文词库有 122,797 条词语及 28,240 条成语，`苹果`实际命中。六套英文词库用于英文词形、重排与网格搜词，没有词义释义；用途本来就区分语言，不算古典音乐式漏接中文名称。
- **科普**：231 篇文章的 1,651 段正文段落均包含中文，主题说明不是纯英文。逐篇来源条目累计有 837 项标记英文、409 项标记中文（含重复引用），属于原始标准、论文或文献语言，不能等同于中文正文缺失。
- **隐藏字符、文件头、合成音色及音阶**：当前活动所有者已有中文名称。旧文件中残留的英文表不等于当前页面仍使用；C4、F#、Am 等保留音乐标准写法。

另有两类低优先级的阅读适配：图片 EXIF/XMP/IPTC 直接显示原始 JSON，MIDI 保存的音轨 JSON 含英文 GM 乐器名（例如 `acoustic grand piano`、`violin`）。这些不是现有中文实体搜索失效，可增加中文阅读视图，继续保留原文。

附带发现：中文词库界面仍标注 117,552 条，与当前 122,797 条数据不一致。这是数量文案漂移，独立于语言问题；本轮没有修改。

## 7. 后续修正应由谁负责

1. **资料名称层**补充有来源的中文主名、译名及别名，与原始 ID 关联。机场、首都、运输地点、鸟类、天体不能仅凭相似字符串合并；保留原始全量记录和精确来源，不把少量译名当作中文全库。
2. **各资料查询模型**将已展示的中文名、术语和别名纳入同一索引，补繁简、常用异译、中文数字与日期解析。资料条目仍由各领域查询所有者检索，不混入只索引公开工具元数据的全站导航搜索。
3. **共享在线结果展示器**增加中文字段名／单位解释，保留标准原键名、完整原始数据及来源。全文和科学描述的翻译与实体名称匹配分开核验。
4. **覆盖率与回退**分别记录原始数据库完整范围、中文名称覆盖和具体查询支持。无可靠中文名时显示原文及状态，标准标识继续可用。

建议优先处理本节 1 的中文名称查找、八卦繁简一致性以及已展示中文未入索引的问题；其次补齐技术字段解释与在线查询中文名称层；原始图谱、文献和元数据的辅助中文阅读视图排在后面。
